### 9 单电原子和离子
##### 玻恩-奥本海默近似
###### 原子的不含时薛定谔方程
$$
\left(\underbrace{ \frac{{-\hbar \nabla^2}}{2M} }_{ 核动能 }+\underbrace{ \sum_{i}^{} \frac{{-\hbar \nabla_{i}^2}}{2m_{e}} }_{ 电子动能 }+\underbrace{ \sum_{i<j}^{} \frac{e^2}{4\pi\varepsilon_{0}|\vec{r_{i}}- \vec{r_{j}}|} }_{ 电子-电子库伦作用 }+\underbrace{ \sum_{i}^{} -\frac{Ze^2}{4\pi\varepsilon_{0}|\vec{r_{i}}-\vec{R}|} }_{ 电子-核库伦作用 }\right)\underbrace{ \psi(\vec{R},\{\vec{r_{i}}\}) }_{ 核和多电子波函数 }=E\psi(\vec{R},\{\vec{r_{i}}\})
$$
###### 玻恩-奥本海默近似
忽略原子核的量子效应
$$
\left(\sum_{i}^{} \frac{{-\hbar \nabla_{i}^2}}{2m_{e}}+\sum_{i<j}^{} \frac{e^2}{4\pi\varepsilon_{0}|\vec{r_{i}}- \vec{r_{j}}|}+\sum_{i}^{} -\frac{Ze^2}{4\pi\varepsilon_{0}|\vec{r_{i}}-\vec{R}|}\right)\psi(\{\vec{r_{i}}\})=E\psi(\{\vec{r_{i}}\})
$$
$|\vec{r_{i}}- \vec{r_{j}}|$：电子自由度关联
与$R$有关 -> $E(\vec{R})$，势能曲线
距离为零时有势能奇点
##### 两体问题
###### 两离子体系的不含时薛定谔方程
$$
\hat{H}= - \frac{\hbar^2}{2m_{1}}\nabla_{1}^2- \frac{\hbar^2}{2m_{2}}\nabla_{2}^2+V, \ \ \hat{H}\psi(\vec{r_{1}},\vec{r_{2}})=E\psi(\vec{r_{1}},\vec{r_{2}})
$$
###### 质心坐标系与相对坐标
$$
\vec{R}= \frac{{m_{1}\vec{r_{1}}+m_{2}\vec{r_{2}}}}{m_{1}+m_{2}},\ \vec{r}=\vec{r_{1}}-\vec{r_{2}}, \ \psi(\vec{r_{1}},\vec{r_{2}})=\psi(\vec{R},\vec{r})
$$
###### 相对坐标下的哈密顿量
$$
\frac{ \partial  }{ \partial x_{1} }=\frac{ \partial  }{ \partial X } \frac{ \partial X }{ \partial x_{1} } +\frac{ \partial  }{ \partial x } \frac{ \partial x }{ \partial x_{1} } =\frac{m_{1}}{m_{1}+m_{2}}\frac{ \partial  }{ \partial X } +\frac{ \partial  }{ \partial x } \implies \nabla_{1}=\frac{m_{1}}{m_{1}+m_{2}}\nabla_{R}+\nabla_{r},\nabla_{2}=\frac{m_{2}}{m_{1}+m_{2}}\nabla_{R}-\nabla_{r}
$$
其中 $$X= \frac{{m_{1}x_{1}+m_{2}x_{2}}}{m_{1}+m_{2}}, x=x_{1}-x_{2}$$
$$
\begin{aligned}\implies \hat{H}=-\frac{\hbar^2}{2m_{1}}\left( \frac{m_{1}}{m_{1}+m_{2}}\nabla_{R}+\nabla_{r} \right)^2-\frac{\hbar^2}{2m_{2}}\left( \frac{m_{2}}{m_{1}+m_{2}}\nabla_{R}-\nabla_{r} \right)^2+V(r)\\ =- \frac{\hbar^2}{2(m_{1}+m_{2})}\nabla_{R}^2- \frac{\hbar^2}{2\mu}\nabla_{r}^2+V(r) \end{aligned} 
$$其中 $$\mu=\frac{m_{1}m_{2}}{m_{1}+m_{2}}$$
$$
\xrightarrow{变量分离}\left[\frac{\hbar^2}{2(m_{1}+m_{2})}\nabla_{R}^2- \frac{\hbar^2}{2\mu}\nabla_{r}^2+V(r)\right]\psi(\vec{R},\vec{r})=E_{T}\psi(\vec{R}-\vec{r}),\ \psi=\phi(\vec{r})\varphi(\vec{R})
$$其中$E_{T}$表示体系总能量
$$
\implies \left\{ \begin{aligned} & - \frac{\hbar^2}{2(m_{1}+m_{2})}\nabla_{R}^2\varphi(\vec{R})=(E_{T}-E)\varphi(\vec{R}) \leftarrow 自由粒子的薛定谔方程\\&\left( - \frac{\hbar^2}{2\mu}\nabla_{r}^2+V(r) \right)\phi(\vec{r})=E\phi(\vec{r}) \leftarrow 两体相对运动的薛定谔方程\end{aligned}\right.
$$
与玻恩-奥本海默近似相比，这里只改变了单体的质量
##### 氢原子与类氢离子
唯一能求精确解析解的一类原子，只包含一个电子和一个原子核，在玻恩-奥本海默近似或只考虑两体相互运动时为单体问题
$$
\left( - \frac{\hbar^2}{2\mu}\nabla^2- \frac{Ze^2}{4\pi\varepsilon_{0}r} \right)\psi=E\psi
$$
###### 球坐标系下的波函数偏导
$$
\left\{ \begin{aligned} &\frac{ \partial \psi }{ \partial r } =\frac{ \partial \psi }{ \partial x } \frac{ \partial x }{ \partial r } +\frac{ \partial \psi }{ \partial y } \frac{ \partial y }{ \partial r } +\frac{ \partial \psi }{ \partial z } \frac{ \partial z }{ \partial r } =\sin \theta \cos \phi\frac{ \partial \psi }{ \partial x } +\sin \theta \sin \phi \frac{ \partial \psi }{ \partial y } +\cos \theta \frac{ \partial \psi }{ \partial z } \\&\frac{ \partial \psi }{ \partial \theta } =\frac{ \partial \psi }{ \partial x } \frac{ \partial x }{ \partial \theta } +\frac{ \partial \psi }{ \partial y } \frac{ \partial y }{ \partial \theta } +\frac{ \partial \psi }{ \partial z } \frac{ \partial z }{ \partial \theta } =r\cos \theta \cos \phi\frac{ \partial \psi }{ \partial x } +r\cos \theta \sin \phi \frac{ \partial \psi }{ \partial y } - r\sin\theta \frac{ \partial \psi }{ \partial z }
 \\ &\frac{ \partial \psi }{ \partial \phi } =\frac{ \partial \psi }{ \partial x } \frac{ \partial x }{ \partial \phi } +\frac{ \partial \psi }{ \partial y } \frac{ \partial y }{ \partial \phi } +\frac{ \partial \psi }{ \partial z } \frac{ \partial z }{ \partial \phi } =-r\sin \theta \sin \phi\frac{ \partial \psi }{ \partial x } +r\sin \theta \cos \phi \frac{ \partial \psi }{ \partial y } \end{aligned} \right.\\
$$

$$
\implies \left\{ \begin{aligned} & \frac{ \partial \psi }{ \partial x } =\sin \theta \cos \phi \frac{ \partial \psi }{ \partial r } +\frac{1}{r}\cos \theta \cos \phi \frac{ \partial \psi }{ \partial \theta } -\frac{1}{r\sin \theta}\sin \phi \frac{ \partial \psi }{ \partial \phi } \\ & \frac{ \partial \psi }{ \partial y } =\sin \theta \sin \phi \frac{ \partial \psi }{ \partial r } +\frac{1}{r}\cos \theta \sin \phi \frac{ \partial \psi }{ \partial \theta }+\frac{1}{r\sin\theta}\cos \phi \frac{ \partial \psi }{ \partial \phi } \\ &\frac{ \partial \psi }{ \partial z } =\cos \theta \frac{ \partial \psi }{ \partial r } -\frac{1}{r}\sin \theta \frac{ \partial \psi }{ \partial \theta } 
\end{aligned}\right.$$
###### 球坐标系下的总动量算符
$$
\begin{aligned}\nabla \psi&=\frac{ \partial \psi }{ \partial x } \vec{e_{x}}+\frac{ \partial \psi }{ \partial y } \vec{e_{y}}+\frac{ \partial \psi }{ \partial z } \vec{e_{z}}\\&=\left( \sin \theta \cos \phi \frac{ \partial \psi }{ \partial r } +\frac{1}{r}\cos \theta \cos \phi \frac{ \partial \psi }{ \partial \theta } -\frac{1}{r\sin \theta}\sin \phi \frac{ \partial \psi }{ \partial \phi } \right)(\sin \theta \cos \phi  \vec{e_{r}}+\cos\theta \cos \phi\vec{e_{\theta}}-\sin \phi  \vec{e_{\phi}})\\&+\left( \sin \theta \sin \phi \frac{ \partial \psi }{ \partial r } +\frac{1}{r}\cos \theta \sin \phi \frac{ \partial \psi }{ \partial \theta }+\frac{1}{r\sin\theta}\cos \phi \frac{ \partial \psi }{ \partial \phi }  \right)(\sin\theta \sin \phi  \vec{e_{r}}+\cos\theta \sin \phi \vec{e_{\theta}}+\cos \phi  \vec{e_{\phi}}) \\&+\left( \cos \theta \frac{ \partial \psi }{ \partial r } -\frac{1}{r}\sin \theta \frac{ \partial \psi }{ \partial \theta }  \right) (\cos \theta  \vec{e_{r}}-\sin\theta \vec{e_{\theta}}) \\&= \frac{ \partial \psi }{ \partial r }  \vec{e_{r}}+\frac{1}{r}\frac{ \partial  }{ \partial \theta } \vec{e_{\theta}}+\frac{1}{r\sin\theta}\frac{ \partial \psi }{ \partial \phi } \vec{e_{\phi}}
\end{aligned}$$

$$
\implies\hat{p}=-i\hbar\left(\frac{ \partial \psi }{ \partial r }  \vec{e_{r}}+\frac{1}{r}\frac{ \partial  }{ \partial \theta } \vec{e_{\theta}}+\frac{1}{r\sin\theta}\frac{ \partial \psi }{ \partial \phi } \vec{e_{\phi}}\right)$$但不能分别拆开得到分量.
###### 动量分量的厄米算符
$$
\hat{p}_{r}\equiv  \frac{\hat{r}}{r}\cdot  \hat{p}\to \frac{1}{2}\left( \frac{\hat{r}}{r}\cdot\hat{p}+\hat{p}\cdot \frac{\hat{r}}{r} \right)=-i\hbar\left( \frac{ \partial   }{ \partial r } +\frac{1}{r} \right)
$$

$$
\hat{p}_{\theta}=\vec{e}_{\theta}\cdot \hat{p}\to \frac{1}{2}(\vec{e}_{\theta}\cdot \hat{p}+\hat{p}\cdot \vec{e}_{\theta})=-i\hbar \frac{1}{r}\left( \frac{ \partial   }{ \partial \theta }+ \frac{1}{2\tan\theta}  \right)
$$

$$
\hat{p}_{\phi}= -i\hbar \frac{1}{r\sin\theta}\frac{ \partial   }{ \partial \phi } 
$$
###### 动能算符的分量
$$
\hat{T}_{r}=\frac{\hat{p}_{r}^2}{2\mu}=-\frac{\hbar^2}{2\mu}\left( \frac{ \partial ^2 }{ \partial r^2 } +\frac{2}{r}\frac{ \partial   }{ \partial r }  \right)
$$

$$
\hat{T}_{\theta}=\frac{\hat{p}_{\theta}^{2}}{2\mu}=- \frac{\hbar^{2}}{2\mu } \frac{1}{r^{2}} \frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial \psi }{ \partial \theta }  \right)
$$

$$
\hat{T}_{\phi}= \frac{\hat{p}^{2}_{\phi}}{2\mu}=-\frac{\hbar^2}{2\mu}\left( \frac{1}{r^{2}\sin ^{2}\theta}\frac{ \partial^{2}\psi }{ \partial \phi^2 }  \right)
$$
###### 球坐标系下的动能项
$$
\hat{T}\psi=- \frac{\hbar^{2}}{2\mu}\nabla^{2}\psi=- \frac{\hbar^{2}}{2\mu} \frac{1}{r^{2}}\left[ \frac{ \partial   }{ \partial r } \left( r^{2}\frac{ \partial \psi }{ \partial r } \right) + \frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial \psi }{ \partial \theta }  \right)+\frac{1}{\sin ^{2}\theta}\frac{ \partial^{2}\psi }{ \partial \phi^{2} }  \right]
$$
##### 类氢离子的薛定谔方程
$$
\hat{H}\psi=E\psi \implies\left( -\frac{\hbar^{2}}{2\mu} \nabla^{2}-\frac{Ze^{2}}{4\pi\varepsilon_{0}}r\right)\psi=E\psi \leftarrow 类似无穷深球形势箱
$$
$$
\implies - \frac{\hbar^{2}}{2\mu r^{2}}\left[ \frac{ \partial   }{ \partial r } \left( r^{2}\frac{ \partial \psi }{ \partial r }  \right)+\frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial \psi }{ \partial \theta }  \right)+\frac{1}{\sin ^{2}\theta }\frac{ \partial^{2}\psi }{ \partial \phi^{2} }  \right]-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}\psi=E\psi
$$

$$
变量分离 \implies \left\{ \begin{aligned} &- \frac{\hbar^{2}}{2\mu r^{2}}\frac{ \partial   }{ \partial r } \left( r^{2}\frac{ \partial \psi }{ \partial r }  \right)-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}\psi=\left( E-\frac{\hbar^{2}\beta}{2\mu r^{2}} \right)\psi \\ &- \frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial \psi }{ \partial \theta } \right)-\frac{1}{\sin\theta^{2}}\frac{ \partial^{2}\psi }{ \partial \phi^{2} }=\beta \psi \end{aligned} \right., \beta 为常数$$
$\psi(r,\theta,\phi)=R(r)Y(\theta,\phi)$
###### 径向薛定谔方程
$$
- \frac{\hbar^{2}}{2\mu r^{2}}\frac{ \partial   }{ \partial r } \left( r^{2}\frac{ \partial \psi }{ \partial r }  \right)-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}\psi=\left( E-\frac{\hbar^{2}\beta}{2\mu r^{2}} \right)\psi
\implies - \frac{\hbar^{2}}{2\mu r^{2}}\frac{ \text{d}   }{ \text{d} r } \left( r^{2}\frac{ \text{d}R }{ \text{d}r }  \right)-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}R=\left( E-\frac{\hbar^{2}\beta}{2\mu r^{2}} \right)R
$$
###### 角向薛定谔方程
$$
- \frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial \psi }{ \partial \theta } \right)-\frac{1}{\sin\theta^{2}}\frac{ \partial^{2}\psi }{ \partial \phi^{2} }=\beta \psi  \implies - \frac{1}{\sin\theta} \frac{ \partial   }{ \partial \theta } \left( \sin\theta \frac{ \partial Y }{ \partial \theta }  \right)-\frac{1}{\sin\theta^{2}}\frac{ \partial^{2}Y }{ \partial \phi^{2} } =\beta Y
$$
角向波函数分离变量：$Y(\theta, \phi)=\Theta(\theta)\Phi(\phi)$
$$
原式\implies -\frac{1}{\sin\theta}\frac{ \text{d}   }{ \text{d} \theta } \left( \sin\theta \frac{ \text{d} \Theta }{ \text{d} \theta }  \right)\Phi - \frac{1}{\sin ^{2}\theta}\frac{ \text{d} ^{2} \Phi}{ \text{d} \phi^{2} }\Theta =\beta\Theta\Phi \implies \frac{1}{\Phi}\frac{ \text{d} ^{2}\Phi }{ \text{d} \phi^{2} } +\left[ \beta \sin ^{2}\theta+\frac{\sin\theta}{\Theta}\frac{ \text{d}   }{ \text{d} \theta } \left( \sin\theta \frac{ \text{d} \Theta }{ \text{d} \theta }  \right) \right]=0
$$
$$
\implies \left\{ \begin{aligned} &\frac{1}{\Phi}\frac{ \text{d} ^{2}\Phi }{ \text{d} \phi^{2} }=-\alpha \ \ 角向方程1\\ &\beta \sin ^{2}1\theta+\frac{\sin\theta}{\Theta}\frac{ \text{d}   }{ \text{d} \theta } \left( \sin\theta \frac{ \text{d} \Theta }{ \text{d} \theta }  \right)=\alpha\ \ 角向方程2\end{aligned}\right.$$
因此，薛定谔方程被拆分成一个径向方程和两个角向方程，通过两个参数$\alpha$和$\beta$关联
###### 解角向波函数
令$\alpha=m^{2},\ \beta=l(l+1)$
得球谐函数 $$
Y_{lm}(\theta,\phi)=\sqrt{ \frac{{2l+1}}{4\pi} \frac{{(l-|m|)!}}{(l+|m|)!} }P_{l}^{|m|}(\cos\theta)e^{ im\phi },\ \ l=0,1,2,\cdots;\ m=0,\pm 1,\pm 2, \cdots
$$其中连带勒让德多项式 $$
P_{l}^{|m|}(x)=\frac{1}{2^ll!}(1-x^{2})^{|m|/2}\frac{ \text{d} ^{l+|m|} }{ \text{d} x^{l+|m|} } (x^{2}-1)^l$$
典型的球谐函数有 $$
Y_{0,0}(\theta,\phi)=\sqrt{ \frac{1}{4\pi} },\ Y_{1,0}(\theta,\phi)=\sqrt{ \frac{3}{4\pi} }\cos\theta, \ Y_{1,\pm 1}(\theta,\phi)=\mp \sqrt{ \frac{3}{8\pi} }\sin\theta e^{ \pm i\phi }
$$

$$Y_{2,0}(\theta,\phi)=\sqrt{ \frac{5}{16\pi} }(3\cos ^{2}\theta-1), \ Y_{2,\pm 1}(\theta, \phi)= \mp \sqrt{ \frac{15}{8\pi} }\sin\theta \cos\theta e^{ \pm i\phi }, \ Y_{2, \pm 2}(\theta,\phi)=\sqrt{ \frac{15}{32\pi} }\sin ^{2}\theta e^{ \pm i {2}\phi }$$
###### 轨道角动量算符
$$\mathbf{L=r\times p}$$
$$\left\{ \begin{aligned} & \frac{ \partial }{ \partial x } =\sin \theta \cos \phi \frac{ \partial  }{ \partial r } +\frac{1}{r}\cos \theta \cos \phi \frac{ \partial  }{ \partial \theta } -\frac{1}{r\sin \theta}\sin \phi \frac{ \partial  }{ \partial \phi } \\ & \frac{ \partial }{ \partial y } =\sin \theta \sin \phi \frac{ \partial  }{ \partial r } +\frac{1}{r}\cos \theta \sin \phi \frac{ \partial }{ \partial \theta }+\frac{1}{r\sin\theta}\cos \phi \frac{ \partial }{ \partial \phi } \\ &\frac{ \partial  }{ \partial z } =\cos \theta \frac{ \partial }{ \partial r } -\frac{1}{r}\sin \theta \frac{ \partial  }{ \partial \theta } 
\end{aligned}\right. \implies \left\{ \begin{aligned} & \mathbf{L}_{x}=-i\hbar \left( -\sin \phi \frac{ \partial   }{ \partial \theta } -\cos \phi \cot\theta \frac{ \partial   }{ \partial \phi } \right)\\& \mathbf{L}_{y}=-i\hbar\left( \cos \phi \frac{ \partial   }{ \partial \theta } -\sin \phi \cot\theta \frac{ \partial   }{ \partial \phi }  \right)\\&\mathbf{L}_{z}=-i\hbar \frac{ \partial   }{ \partial \phi } \end{aligned}\right.
$$
$$\mathbf{L}^{2}=-\hbar^{2}\left[ \frac{1}{\sin\theta}\frac{ \partial   }{ \partial \theta } \left( \sin \theta \frac{ \partial   }{ \partial \theta }  \right)+\frac{1}{\sin ^{2}\theta}\frac{ \partial^{2} }{ \partial \phi^{2} }  \right] \implies \left\{ \begin{aligned}& \mathbf{L}^2 Y_{lm}=l(l+1)\hbar^{2}Y_{lm} \ \to\text{ l为角量子数}\\&\mathbf{L}_{z}Y_{lm}=m\hbar Y_{lm} \to \text{ m为磁量子数} \end{aligned} \right.$$
轨道角动量在空间上分立分布，具有量子基本特征.
###### 解径向波函数
将$\beta$代入得 $$
- \frac{\hbar^{2}}{2\mu r^{2}}\frac{ \text{d}   }{ \text{d} r } \left( r^{2}\frac{ \text{d}R }{ \text{d}r }  \right)-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}R=\left( E-\frac{l(l+1)\hbar^{2}}{2\mu r^{2}} \right)R \implies\left[ -\frac{\hbar^{2}}{2\mu}\left( \frac{ \text{d} ^{2} }{ \text{d} r^{2} } +\frac{2}{r }\frac{ \text{d}  }{ \text{d} r }  \right)-\frac{Ze^{2}}{4\pi\varepsilon_{0}r}+\frac{l(l+1)\hbar^{2}}{2\mu r^{2}} \right]R=ER
$$

$$
\implies \ddot{R}+\frac{2}{r}\dot{R}+\left( \frac{8\pi\varepsilon_{0}E}{a_{0}e^{ 2 }}+\frac{2Z}{a_{0}r}-\frac{l(l+1)}{r^{2}} \right)R=0, \ a_{0}\equiv \frac{4\pi\varepsilon_{0}\hbar^{2}}{\mu e^{2}} \text{: Bohr's radius}
$$
解方程得 $$
R_{nl}(r)=\sqrt{ \left( \frac{2Z}{n} \right)^{3} {\frac{(n-l-1)!}{2n[(n+l)!]}} }e^{ -Zr/na_{0} }\left( \frac{2Zr}{na_{0}} \right)^lL^{2l+1}_{n-l-1}\left( \frac{2Zr}{na_{0}} \right)
$$其中伴随拉盖尔多项式 $$
L^\alpha_{n}(x)\equiv x^{-\alpha} \frac{1}{n!}\left( \frac{ \text{d}   }{ \text{d} x } -1 \right)^n x^{n+\alpha}
$$
解得本征态能量 $$
E_{n}=-\frac{Z^{2}}{n^{2}} \frac{e^{2}}{8\pi\varepsilon_{0}a_{0}}=-\frac{Z^{2}\mu e^4}{8\varepsilon_{0}^{2}n^{2}\hbar^{2}},\ n=1,2,\cdots 称主量子数; \ l=0,1,\cdots, n-1 
$$
典型的径向波函数有 $$
R_{10}(r)\equiv R_{1s}(r)=\left( \frac{Z}{a_{0}} \right)^{3/2}2e^{ -Zr/a_{0} }, \ R_{20}(r)\equiv R_{2s}(r)=\left( \frac{Z}{2a_{0}} \right)^{3/2}\left( 2- \frac{Z}{a_{0}}r \right)e^{ -\frac{Zr}{2a_{0}} }$$ $$\ R_{21}(r)\equiv R_{2p}(r)=\left( \frac{Z}{2a_{0}} \right)^{3/2} \frac{Z}{a_{0}\sqrt{ 3 }}re^{ -\frac{Zr}{2a_{0}} },\ R_{30}(r)\equiv R_{3s}(r)=\left( \frac{Z}{3a_{0}} \right)^{3/2}\left( 2- \frac{4Z}{3a_{0}}r+\frac{4Z^{2}}{27a_{0}^{2}}r^{2} \right)e^{ -\frac{Zr}{3a_{0}} }
$$

$$
R_{31}(r)\equiv R_{3p}(r)=\left( \frac{2Z}{a_{0}} \right)^{3/2}\left( \frac{2Z}{27\sqrt{ 3 }a_{0}}r-\frac{Z^{2}}{81\sqrt{ 3 }a_{0}^{2}}r^{2} \right)e^{ -\frac{Zr}{3a_{0}} },\ R_{32}(r)\equiv R_{3d}(r)=\left( \frac{2Z}{a_{0}} \right)^{3/2} \frac{Z^{2}}{81\sqrt{ 15 }a_{0}^{2}}r^{2}e^{ -\frac{Zr}{3a_{0}} }$$
##### 原子轨道
综上，氢原子和类氢离子的本征态成为原子轨道，由三个参数：主量子数n、角量子数l、磁量子数m描述，本征值由n决定. 最低的本征态称为基态，其他本征态称为激发态.
$$
\psi_{nlm}(r,\theta,\phi)=R_{nl}(r)Y_{lm}(\theta,\phi), \ E_{n}= -\frac{Z^{2}\mu e^4}{8\varepsilon_{0}^{2}n^{2}\hbar^{2}}, \ n=1,2,\cdots; l =0, 1, \cdots,n-1; m= 0,\pm 1,\cdots,\pm l.
$$
能级$E_n$的简并度 $$
f_{n}=\sum_{l=0}^{n-1} (2l+1)=n^{2}.$$
##### 宇称
取对称：$\vec{r}\to -\vec{r}$，即$r\to r,\ \theta\to \pi-\theta,\ \phi \to \pi+\phi$，则原子轨道$$
R_{nl}(r)Y_{lm}(\theta,\phi)\to R_{nl}(r)Y_{lm}(\pi-\theta,\pi+\phi)
$$其中 $$
\begin{align}& Y_{lm}(\theta,\phi)\sim P_{l}^{|m|}(\cos\theta)e^{ im\phi }, \ P_{l}^{|m|}(x)=\frac{1}{2^ll!}(1-x^{2})^{|m|/2}\frac{ \text{d} ^{l+|m|} }{ \text{d} x^{l+|m|} } (x^{2}-1)^l \\ & \implies Y_{lm}(\pi-\theta,\pi+\phi)=(-1)^{m+l}e^{ i\pi m }Y_{lm}(\theta,\phi)=(-1)^{2m+l}Y_{lm}(\theta,\phi)=(-1)^lY_{lm}(\theta,\phi)\end{align} 
$$
因此 $$
\psi_{nlm}(-\vec{r})=(-1)^l\psi_{nlm}(\vec{r}) \leftarrow l决定宇称
$$
若波函数变号，则称为奇宇称；若符号不变，则称为偶宇称。
##### 氢原子光谱
量子力学得出了氢原子光谱中所有谱线的位置，误差小于万分之一。
核量子效应和相对论效应（标量相对论效应和）的主要来源。
