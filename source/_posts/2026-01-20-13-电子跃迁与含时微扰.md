### 13 电子跃迁与含时微扰
##### 分子-电磁场相互作用
###### 电子跃迁
电磁波与分子相互作用，导致电子在量子化的能级间进行跃迁，并导致光的吸收和发射，电子跃迁与光谱紧密关联。磁场与电子磁矩的相互作用可以忽略，而且分子周围的电场可以假设为均匀电场。
###### 电偶极与电场相互作用
偶极矩：从正电荷指向负电荷
$$\mu _{z}=\sum _{i}q_{i}z_{i}\implies  \left| \mu _{z} \right|=ql $$
含时电场
$$E(t)=E\cos\omega t$$
相互作用哈密顿量
$$\hat{H}'(t)=-\sum _{i}q_{i}E(t)z_{i}=-\mu _{z}E\cos\omega t$$
电磁场作用于分子是电子偶极矩与振荡电场之间的相互作用
##### 电场下的电子跃迁
###### 能级间的电子动力学
在电磁场中，如果电子初始处于$k$态，计算$m$态上的电子布居随时间的变化可以得到其跃迁速率。
如果$E_k<E_m$，该速率对应光吸收；如果$E_k>E_m$，则对应受激发射。
###### 含时动力学计算
初始波函数
$$\psi(0)=\phi _{k}$$
含时哈密顿量
$$\hat{H}=\hat{H}_{0}+\hat{H}'(t),\qquad \hat{H}'(t)=\left\{\begin{aligned}
&0, & t<0\\ & -\mu _{z}E\cos\omega t, & t\geq 0
\end{aligned}\right.$$
含时薛定谔方程
$$\frac{ \partial \psi(t) }{ \partial t } =\frac{\hat{H}(t)\psi(t)}{i\hbar}$$
假设$\hat{H}'(t)$相对于$\hat{H}_{0}$是小量，可以使用含时微扰理论近似计算。
##### 含时微扰理论
基于非微扰哈密顿量的本征态，近似计算微扰存在时的含时波函数。
体系哈密顿量
$$\hat{H}=\hat{H}_{0}+\underbrace{ \hat{H}'(t) }_{ \text{含时微扰} }$$
含时薛定谔方程
$$i\hbar\frac{ \partial   }{ \partial t } \Psi(t)=\hat{H}(t)\Psi(t)$$
非微扰部分的定态薛定谔方程
$$\hat{H}_{0}\psi _{n}=\varepsilon _{n}\psi _{n}$$
含时基组（相互作用绘景下，将总波函数写成对$\hat{H_{0}}$本征态随时间的简正演化乘以未知的含时系数的线性组合）
$$\left.\begin{aligned}
&\Psi_{n}(0)=\psi _{n}\\ &i\hbar \frac{ \partial   }{ \partial t } \Psi_{n}(t)=\hat{H}_{0}\Psi_{n}(t)
\end{aligned}\right\} \implies \Psi_{n}(t)=\psi _{n}e^{ -i\varepsilon _{n}t/\hbar }$$
含时波函数的基组展开形式
$$\Psi(t)=\sum _{n}a_{n}(t)\Psi_{n}(t)$$
###### 含时波函数系数的演化方程
$$\begin{align}& i\hbar \frac{ \partial   }{ \partial t } \left( \sum _{n}a_{n}(t)\Psi_{n} \right) =\hat{H}(t)\left( \sum _{n}a_{n}(t)\Psi_{n} \right)\\& \implies i\hbar \sum _{n}\frac{ \partial a_{n}(t) }{ \partial t } \Psi_{n}+\sum _{n}a_{n}(t)\hat{H}_{0}\Psi_{n}=(\hat{H}_{0}+\hat{H}'(t))\left( \sum _{n}a_{n}(t)\Psi_{n} \right)\\&\text{非微扰部分正好能给出相同的相位依赖，因此左右相互抵消得到}\\&\implies  i\hbar \sum _{n}\frac{ \partial a_{n}(t) }{ \partial t } \Psi_{n}=\hat{H}'(t)\left( \sum _{n}a_{n}(t)\Psi_{n} \right)\\&\text{为了得到系数的演化方程，令左右同乘}\Psi _{m}^{*}\text{再对坐标积分（即投影到其上），由正交性有}\\&\implies i\hbar \sum _{n}\frac{ \partial a_{n}(t) }{ \partial t } \left( \int \Psi_{m}^{*}\Psi_{n}\text{d}r \right)=\sum _{n}a_{n}(t)\left( \int \Psi_{m}^{*}\hat{H}'(t)\Psi_{n}\text{d}r \right) \\&\text{左边得狄利克雷符号，右边由}\Psi_{n}(t)=\psi _{n}e^{ -i\varepsilon _{n}t/\hbar }\text{有}\\&\implies i\hbar \sum _{n}\frac{ \partial a_{n}(t) }{ \partial t }\delta _{mn}=\sum _{n}a_{n}(t)\left( \int \psi _{m}^{*}\hat{H}'(t)\psi _{n}\text{d}r \right)e^{ i(\varepsilon _{m}-\varepsilon _{n})t/\hbar }\\&\implies i\hbar \frac{ \partial a_{m}(t) }{ \partial t } =\sum _{n}a_{n}(t)H_{mn}'e^{ i\omega _{mn}t },\quad 其中H'_{mn}=\int \psi _{m}^{*}\hat{H}'(t)\psi _{n}\text{d} r,\quad \omega _{mn}=\frac{{\varepsilon _{m}-\varepsilon _{n}}}{\hbar}\end{align}  $$
###### 含时波函数系数的近似演化
1. 引入一个参数$\lambda$，用$\lambda \hat{H}'$代替$\hat{H}'$：$\lambda=0$，对应无扰动体系；将$\lambda$从0调至1，就慢慢将扰动引入。再把依赖$\lambda$展开的解再回到$\lambda=1$，就得到真正的微扰解。
2. 将$a_{n}(t)$在基态空间展开，每个展开系数$a_{n}(t)$随时间变化，由于扰动$\hat{H}'(t)$较小，假设其按照$\lambda$幂级数展开
   $$a_{n}(t)=a_{n}^{(0)}(t)+\lambda a_{n}^{(1)}+\lambda^{2}a_{n}^{(2)}+\dots$$
3. 将上式代入含时波函数系数的演化方程
   $$i\hbar \left[ \frac{ \partial a_{m}^{(0)} }{ \partial t } +\lambda \frac{ \partial a_{m}^{(1)} }{ \partial t } +\lambda^{2}\frac{ \partial a_{m}^{(2)} }{ \partial t } +\dots \right]=\sum _{n}[a_{n}^{(0)}+\lambda a_{n}^{(1)}+\lambda^{2}a_{n}^{(2)}+\dots]\lambda H_{mn}'e^{ i\omega _{mn}t } $$
4. 要使等式在任意$\lambda$下成立，就需要同阶系数分别相等，即按$\lambda$幂次分类得到各级运动方程：
   $$\frac{ \partial a_{m}^{(0)} }{ \partial t } =0,\qquad i\hbar \frac{ \partial a_{m}^{(1)} }{ \partial t } =\sum _{n}a_{n}^{(0)}H_{mn}'e^{ i\omega _{mn}t },\qquad i\hbar \frac{ \partial a_{m}^{(2)} }{ \partial t } =\sum _{n}a_{n}^{(1)}H_{mn}'e^{ i\omega _{mn}t }$$
5. 令$\lambda=1$，得到含时波函数$\lambda$的各级近似解。
###### 线性含时微扰
假设$t\leq0$，体系仅受$\hat{H}_{0}$主导，体系处于$\hat{H}_{0}$的第k个本征态$\psi _{k}$，则0阶部分在t=0时，若$n=k$，系数为1；否则为0。对于1阶及更高阶部分，在t=0时不存在微扰造成的修正。由于0阶系数在无扰下只随相位演化，即在相互作用绘景下为常数：
$$\begin{align}\psi _{k}=\sum _{n}a_{n}(0)\Psi_{n}(0)=\sum _{n}[a_{n}^{(0)}\Psi_{n}(0)+\lambda a_{n}^{(1)}+\dots]\psi _{n}&\implies \delta _{nk}=a_{n}^{(0)}(0)+\lambda a_{n}^{(1)}(0)+\dots \\ & \implies \left\{\begin{aligned}
&a_{n}^{(0)}(0)=\delta _{nk}\\ & a_{n}^{(1)}(0)=a_{n}^{(2)}(0)=\dots=0
\end{aligned}\right.  \end{align} $$
因为$a_{n}^{(0)}(0)$不含时，故$a_{n}^{(0)}(t)=a_{n}^{(0)}(0)=\delta _{nk}$
$t>0$后加入微扰，作第一阶近似即线性含时微扰，求和仅保留$n=k$一项，可直接积分：
$$i\hbar \frac{ \partial a_{m}^{(1)} }{ \partial t } =\sum _{n}a_{n}^{(0)}H_{mn}'e^{ i\omega _{mn}t }=H_{mk}'e^{ i\omega _{mk}t }\implies a_{m}^{(1)}(t)=\frac{1}{i\hbar}\int_{0}^{t} H_{mk}'e^{ i\omega _{mk}t' } \, \text{d}t' $$
###### 量子跃迁几率
含时波函数
$$\Psi(t)=\sum_{m}a_{m}(t)\Psi_{m}(t)$$
波函数系数

$$a_{m}(t)=a_{m}^{(0)}(t)+a_{m}^{(1)}(t)+a_{m}^{(2)}(t)+\dots=\delta _{mk}+ \frac{1}{i\hbar}\int_{0}^{t} H_{mk}'e^{ i\omega _{mk}t' } \, \text{d}t'+\dots $$
若末态m不等于初态k
$$a_{m}(t)= \frac{1}{i\hbar}\int_{0}^{t} H_{mk}'(t)e^{ i\omega _{mk}t' } \, \text{d}t'+\dots $$
在微扰作用下, t时刻体系处于末态$\Psi_{m}$的机率为
$$W_{k\to m}=\lvert a_{m}(t) \rvert ^{2}\approx \left\lvert  \frac{1}{i\hbar}\int_{0}^{t} H_{mk}'(t)e^{ i\omega _{mk}t' } \, \text{d}t'   \right\rvert ^{2}$$
###### 跃迁速率
$$\omega _{k\to m}=\frac{\text{d}W_{k\to m}}{\text{d}t} $$
##### 有限时间常微扰
###### 含时哈密顿量
$$\hat{H}'=\left\{\begin{aligned}&
0, &&t<0\\&\hat{H}'(\vec{r})& & 0\leq t<t_{1} \\ &0 &&t>t_{1}
\end{aligned}\right.$$
###### 线性含时微扰
$$\begin{aligned}W_{k\to m}&=\left\lvert  \frac{1}{i\hbar}\int_{0}^{t} H_{mk}'(t)e^{ i\omega _{mk}t' } \, \text{d}t'   \right\rvert ^{2}=\left\lvert  \frac{H_{mk}'}{i\hbar}\int_{0}^{t} e^{ i\omega _{mk}t' } \, \text{d}t'   \right\rvert ^{2}=\left\lvert  \frac{H_{mk}'}{i\hbar} \frac{1}{i\omega _{mk}}\left.e^{ i\omega _{mk}t }\right|_{0}^{t_{1}}  \right\rvert^{2}=\left| \frac{H_{mk}'}{-\hbar\omega _{mk}}(e^{ i\omega _{mk}t_{1} }-1) \right|^{2} \\& =\left| \frac{H_{mk}'}{-\hbar\omega _{mk}}e^{ i\omega _{mk}t_{1}/2 }(e^{ i\omega _{mk}t_{1}/2}-e^{ -i\omega _{mk}t_{1}/2 }) \right|^{2}= \left| \frac{H_{mk}'}{-\hbar\omega _{mk}}2e^{ i\omega _{mk}t_{1}/2 }\sin\left( {\frac{\omega _{mk}t_{1}}{2} } \right) \right|^{2}=\frac{{4\lvert H_{mk}' \rvert ^{2}\sin ^{2} \frac{\omega _{mk}t_{1}}{2}}}{\hbar^{2}\omega _{mk}^{2}}\end{aligned}  $$
##### 费米黄金规则
###### 长时极限的跃迁速率
下左式称正则极限，表明当$\alpha\to{0}$时，$\sin ^{2}(\alpha x)$变得极为尖锐和高耸，而其面积仍为常数，从而逼近$\delta$函数。随时间增长，跃迁概率中出现振荡因子$\sin ^{2} (\frac{\omega _{mk}t}{2})$，对其归一化为$\delta$函数，表明能量守恒选区只在$\omega _{mk}=0$时有非零贡献。将其代入线性含时微扰跃迁概率，除以时间就得到单位时间的跃迁概率即跃迁速率：
$$\begin{aligned}\lim_{ a \to 0 } \frac{{\sin ^{2}\alpha x}}{\pi\alpha x^{2}}= \delta(x) &\implies \lim_{ t_{1} \to 0 } \frac{{\sin ^{2} \frac{\omega _{mk}t_{1}}{2}}}{\frac{\omega _{mk}^{2}t_{1}}{4}}=\pi\delta  \left(\frac{\omega_{mk}}{2}\right)=2\pi \hbar\delta(\varepsilon _{m}-\varepsilon _{k}) \\ &\implies \lim_{ t_{1} \to 0 } W_{k\to m}=\frac{2\pi t_{1}}{\hbar}\lvert H_{mk}' \rvert ^{2}\delta(\varepsilon _{m}-\varepsilon _{k})\\&\implies \omega _{k\to m}=\frac{\text{d}W_{k\to m}}{\text{d}t_{1}}=\frac{2\pi}{\hbar}\lvert H_{mk}' \rvert ^{2}\delta(\varepsilon _{m}-\varepsilon _{k})  \end{aligned} $$
上式表明，长时极限（演化时间足够长，相当于能量分辨极好）下，与$\varepsilon _{k}$不同的末态会因快速振荡而相互抵消贡献，只剩最匹配能量的部分，因此跃迁速率与时间无关，且只有在初态能量小范围内（$\varepsilon _{m}$和$\varepsilon _{k}$态能量相同或差在极小范围内）才有跃迁几率，否则为0. 因此，在微扰跃迁中，若无其他外部能量交换（如光子吸收/发射），最有效的跃迁只在末态和初态能量相同处发生，这对应了对角（能量匹配）条件。
###### 费米黄金规则
实际体系中，末态$\ket{m}$不仅是离散能量的一态，而可能在某个能量区间内有很多近似可用态。记$\rho(\varepsilon)$为态密度，则体系在末态能量$\varepsilon _{m}$附近$\text{d}\varepsilon _{m}$范围内的态数目是$\rho(\varepsilon _{m})\text{d}\varepsilon _{m}$, 则总跃迁速率为
$$\omega=\int \rho(\varepsilon _{m})\omega _{k\to m}\text{d}\varepsilon _{m}=\int \rho(\varepsilon _{m}) \frac{2\pi}{\hbar}\lvert H_{mk}' \rvert ^{2}\delta(\varepsilon _{m}-\varepsilon _{k})\text{d}\varepsilon _{m}=\frac{2\pi}{\hbar}\lvert H_{mk}' \rvert ^{2}\rho(\varepsilon _{k})$$
费米黄金规则适用于真实材料和连续谱系统，即末态不是单一能级而是集中于某能量段内，考虑了微扰矩阵元和可用末态数（态密度），常用于估计跃迁（反应）速率。
##### 跃迁偶极
根据费米黄金规则，从初态$\ket{k}$向末态$\ket{m}$的跃迁速率可以写成如下形式，其中$\left| H_{mk}' \right|^{2}$决定跃迁几率大小，$\delta(\varepsilon _{m}-\varepsilon _{k})$体现了能量匹配条件。在最简单的电偶极近似下，只考虑均匀电场沿$z$方向，偶极矩为$\hat{\mu}_{z}=e \vec{r}$，则有费米黄金规则的一阶微扰跃迁率为
$$\left\{\begin{aligned}&
\omega _{k\to m}=\frac{2\pi}{\hbar}\lvert H_{mk}' \rvert ^{2}\delta(\varepsilon _{m}-\varepsilon _{k})\propto \lvert H_{mk}' \rvert ^{2}\\&\hat{H}^{2}=-\mu _{z}E
\end{aligned}\right.\implies \omega _{k\to m}\propto \lvert \mu _{z,mk} \rvert ^{2}E^{2}$$
**电子的跃迁速率正比于电场平方, 也正比于电场方向跃迁偶极的平方.** 
跃迁偶极矩定义为
$$\mu _{mk}=\int \psi _{m}^{*}\hat{\mu}\psi _{k}\text{d}r=\int \psi _{m}^{*}e\vec{r}\psi _{k}\text{d}r=e\int \psi _{m}^{*}\vec{r}\psi _{k}\text{d}r$$
如果仅关心$z$方向分量，则
$$\mu _{z,mk}=e\int \psi _{m}^{*}z\psi _{k}\text{d}r$$
其代表初态$\psi _{k}$和末态$\psi _{m}$与算符$\hat{\mu}$的重叠积分。
与宇称相关, 与偶极矩截然不同.
- 电偶极矩 $\braket{ \psi _{k} | \vec{r}|\psi _{k} }$ 指单个态本身的期望值，用于判断该态是否有永久电偶极；
- 跃迁偶极矩 $\braket{ \psi _{m} | \vec{r}|\psi _{k} }$ 则需要两个不同态共同参与，对应初态与末态之间的偶极跃迁强度；
- 若$\psi _{k}$和$\psi _{m}$具有相同的宇称，则该积分可能由于正负区域抵消。
入射光的吸收强度对应于电子的跃迁速率，因此也正比于跃迁偶极的平方。
- 光与物质相互作用时，经典电场振幅$E$出现在哈密顿量$\hat{H}'$中的线性项，因此跃迁速率$\propto E^{2}$；
- 由于跃迁速率关键是$\left| \braket{ \psi _{m} | \hat{\mu} |\psi _{k}} \right|^{2}$，这说明态重叠越显著，即波函数对称匹配越好，对于满足$\varepsilon _{m}-\varepsilon _{k}=\hbar\omega$的光子的能量吸收就越强。
##### 周期微扰
###### 含时哈密顿量
$$\hat{H}'=\left\{\begin{aligned}
&0 &&t<0\\ &A\cos\omega t &&t>0
\end{aligned}\right.\implies \hat{H}'(t)\equiv \left\{\begin{aligned}
&0&&t<0\\&F(\vec{r})(e^{ i\omega t }+e^{ -i\omega t })&&t>0
\end{aligned}\right.$$
###### 含时波函数
$$\begin{align}
H_{mk}'&=\int \phi _{m}^{*}\hat{H}'(t)\phi _{k}\text{d}r\\&=\int \phi _{m}^{*}F(e^{ i\omega t }+e^{ -i\omega t })\phi _{k}\text{d}r\\&=\int \phi _{m}^{*}F\phi _{k}\text{d}r(e^{ i\omega t }+e^{ -i\omega t })\\&=F_{mk}(e^{ i\omega t }+e^{ -i\omega t })
\end{align}\qquad \begin{aligned} a_{m}^{(1)}(t)&= \frac{F_{mk}}{i\hbar}\int_{0}^{t} (e^{ i\omega t' }+e^{ -i\omega t' })e^{ i\omega _{mk}t' } \, \text{d}t'\\&= \frac{F_{mk}}{i\hbar}\left.\left[  \frac{e^{ i(\omega _{mk}+\omega)t' }}{i(\omega _{mk}+\omega)}+\frac{e^{ i(\omega _{mk}-\omega)t' }}{i(\omega _{mk}-\omega)}\right]\right|_{0}^{t} \\&=- \frac{F_{mk}}{i\hbar}\left[ \frac{e^{ i(\omega _{mk}+\omega)t }-1}{\omega _{mk}+\omega}+\frac{e^{ i(\omega _{mk}-\omega)t }-1}{\omega _{mk}-\omega} \right] \end{aligned}  $$
###### 周期微扰的含时哈密顿量
$$\hat{H}'=\left\{\begin{aligned}
&0 &&t<0 \\ &A\cos\omega t && t>0
\end{aligned}\right.\implies \hat{H}'(t)\equiv \left\{\begin{aligned}
&0&&t<0 \\ &F(\vec{r})(e^{ i\omega t }+e^{ -i\omega t })&&t>0
\end{aligned}\right.$$
###### 含时波函数
$$\begin{aligned} H_{mk}'&=\int \phi _{m}^{*}\hat{H}'(t)\phi _{k}\text{d}r \\& =\int \phi _{m}^{*}F(e^{ i\omega t }+e^{ -i\omega t })\phi _{k}\text{d}r\\&=\int \phi _{m}^{*}F\phi _{k}\text{d}r(e^{ i\omega t }+e^{ -i\omega t })\\&=F_{mk}(e^{ i\omega t }+e^{ -i\omega t })\end{aligned} \qquad \begin{aligned} a_{m}^{(1)}(t)&=\frac{F_{mk}}{i\hbar}\int _{0}^{t}(e^{ i\omega t' }+e^{ -i\omega t' })e^{ i\omega _{mk}t' } \text{d}t'\\&=-\frac{F_{mk}}{\hbar}\left[ \frac{e^{{i(\omega _{mk}+\omega)t }-1}}{\omega _{mk}+\omega}+\frac{e^{{i(\omega _{mk}-\omega)t }-1}}{\omega _{mk}-\omega} \right] \end{aligned} $$
###### 频率与波函数演化
$$\left\{\begin{aligned}&
\lim_{ \omega \to \omega _{mk} } \frac{e^{{i(\omega _{mk}-\omega)t }-1}}{\omega _{mk}-\omega}=it\implies \lim_{ \omega \to \omega _{mk} } a_{m}^{(1)}(t)=-\frac{F_{mk}}{\hbar}\left( \frac{{e^{ 2i\omega _{mk}t }-1}}{2\omega _{mk}}+it \right)\\&\lim_{ \omega \to -\omega _{mk} } \frac{e^{{i(\omega _{mk}+\omega)t }-1}}{\omega _{mk}+\omega}=it\implies \lim_{ \omega \to -\omega _{mk} } a_{m}^{(1)}(t)=-\frac{F_{mk}}{\hbar}\left( \frac{{e^{ 2i\omega _{mk}t }-1}}{2\omega _{mk}}+it \right)
\end{aligned}\right.$$
这两个极限下，波函数系数有一个随时间线性增加的项，起主要作用。
对于$\omega\neq\pm\omega _{mk}$，波函数系数是一个周期性振荡函数。
###### 共振跃迁
仅当外界微扰含有频率$\omega _{mk}$时，体系才能从k态跃迁到m态，此时体系吸收或发射光的能量为$\hbar\omega _{mk}$。
###### 长时极限的吸收和发射跃迁速率
当$\omega\to\omega _{mk}$时，有
$$a_{m}^{(1)}(t)\approx-\frac{F_{mk}}{\hbar}\left[ \frac{{e^{ i(\omega _{mk}-\omega)t }-1}}{\omega _{mk}-\omega} \right]$$
