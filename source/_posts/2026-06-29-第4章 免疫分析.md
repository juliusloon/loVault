## 一、免疫学基础概念

### 1. 免疫（Immunity）
- **定义**：机体对"自己"和"异己"识别、应答过程中所产生的生物学效应的总和。
- **功能**：正常情况下是维持机体内环境稳定的一种生理功能。

### 2. 免疫学（Immunology）
- **定义**：研究机体免疫系统结构和功能的一门学科。
- **来源**：起源于抗感染免疫（微生物学的分支）。

---

## 二、抗原（Antigen, Ag）

### 1. 抗原的基本概念
- **定义**：引起机体免疫应答的外因，也是决定免疫反应特异性的关键。能刺激机体免疫系统产生抗体或致敏淋巴细胞，并能与之特异性结合的物质统称抗原。
- **常见抗原**：
  1. 进入机体的外来物质：细菌、病毒、花粉等；
  2. 不同物种间的物质：如马的血清进入兔体内；
  3. 同种异体间的物质：如血型抗原、移植免疫等。

### 2. 抗原的特性（双重性）

| 特性 | 定义 | 说明 |
|------|------|------|
| **免疫原性**（immunogenicity） | 刺激机体产生特异性抗体及致敏淋巴细胞的特性 | 涉及 B 细胞活化、T 细胞活化、抗体产生 |
| **免疫反应性/抗原性**（immunoreactivity/antigenicity） | 与相应免疫应答产物（抗体或致敏淋巴细胞）发生特异性结合的特性 | 是抗原识别阶段的关键 |

- **完全抗原**：同时具备免疫原性和免疫反应性的物质。
- **半抗原（Hapten）**：仅具有免疫反应性，**无免疫原性**的物质（如小分子化合物、药物等）。
- **载体（Carrier）**：与半抗原结合而赋予其免疫原性的物质，一般为蛋白质。
  - *关系*：半抗原可视为完全抗原的表位；完全抗原可视为载体上附有若干半抗原。

### 3. 抗原的特异性（Specificity）
- **定义**：抗原诱导机体产生特异性免疫应答并与免疫应答产物发生专一结合的特性。
- **分子基础——抗原表位（Epitope）/抗原决定簇（Antigenic Determinant）**：
  - 抗原分子中决定抗原特异性的特殊基本结构或化学基团；
  - 是 TCR/BCR 及抗体特异性结合的基本单位；
  - 一般由 **5~15 个氨基酸残基**、**5~7 个多糖残基**或核苷酸残基构成一个表位。

#### 表位的类型
| 类型 | 英文 | 结构特点 |
|------|------|----------|
| **线性表位** | Linear epitope | 氨基酸残基在多肽链上**相邻连续**排列 |
| **构象表位/不连续表位** | Discontinuous epitope | 由多肽链**不同部位**的氨基酸残基在空间上折叠靠近形成 |

### 4. 抗原的种类（依据与机体的亲缘关系）

#### （1）异种抗原（Xenogenic Ag）
- 来自不同种属的抗原，如微生物、治疗用动物免疫血清。
- **典型实例——马血清抗毒素的两重性**：
  - 作为**特异性抗体**：中和毒素；
  - 作为**异种抗原**：刺激机体产生抗马血清抗体，引发超敏反应。
  - *流程*：毒素 → 类毒素 → 注射马 → 马血清（含抗毒素抗体）→ 注射人体中和毒素，但同时作为异种抗原引发超敏反应。

#### （2）同种异型抗原（Allogenic Ag）
- 同一种属不同个体之间存在的抗原。
- **典型实例——ABO 血型系统**：

| 血型 | 抗原 | 抗体 |
|:----:|:----:|:----:|
| A | A | 抗 B |
| B | B | 抗 A |
| O | —（H 抗原） | 抗 A、抗 B |
| AB | A、B | — |

#### （3）自身抗原（Autoantigen）
- 正常情况下机体对自身组织细胞不产生免疫应答（**自身耐受**）。
- **形成原因**：感染、外伤、服用某些药物等导致隔离抗原释放，或自身组织抗原结构被改变/修饰。
- **典型实例**：药物与红细胞（RBC）结合后成为自身抗原 → 与自身抗体结合形成抗原抗体复合物 → 激活补体 → 导致**自身免疫性溶血性贫血**。

## 三、免疫球蛋白（Immunoglobulin, Ig）

### 1. 基本概念
- **免疫球蛋白（Ig）**：化学结构上的概念，血液和组织液中的一类糖蛋白。
- **抗体（Ab）**：生物学功能概念，由 B 细胞接受抗原刺激后增殖分化为浆细胞产生，是体液免疫应答的重要效应分子。
- **关系**：所有抗体都是 Ig，但并非所有 Ig 都有抗体活性。

### 2. 免疫球蛋白的结构
#### （1）基本结构（以 IgG 为例）
- **Y 形四肽链结构**：
  - **两条相同的重链（H 链）**
  - **两条相同的轻链（L 链）**
  - 链间以**二硫键**相连。
- **分区**（从 N 端到 C 端）：
  - **可变区（V 区）**：N 端，氨基酸序列变化大，含**超变区（互补决定区, CDR）**，是抗原结合部位。
  - **恒定区（C 区）**：C 端，氨基酸序列相对恒定，决定 Ig 的效应功能。

#### （2）免疫球蛋白的类型（五类）
根据重链恒定区不同分为：**IgG、IgA、IgM、IgD、IgE**。
- **IgG**：单体，血清中含量最高，主要抗感染抗体；
- **IgA**：单体或二聚体（分泌型 IgA，sIgA）；
- **IgM**：五聚体，分子量最大，初次免疫应答早期产生；
- **IgD**：单体，B 细胞表面受体；
- **IgE**：单体，与 I 型超敏反应和抗寄生虫免疫有关。

## 四、抗原抗体反应（Antigen-Antibody Reaction）

### 1. 概述
- **定义**：抗原与相应抗体之间发生的特异性结合反应。
- **发生场所**：体内（in vivo，介导吞噬、溶菌、杀菌、中和毒素）或体外（in vitro）。
- **血清反应**：因抗体主要存在于血清中，体外抗原抗体反应常采用血清作试验，故亦称血清反应（serologic reaction）。

### 2. 抗原抗体反应的特点

| 特点 | 核心内容 |
|------|----------|
| **特异性** | 抗原表位与抗体超变区的抗原结合点呈**互补关系**（如钥匙与锁）。但大分子蛋白质含多种表位，若不同抗原有相同表位可发生**交叉反应**。 |
| **按比例** | 生成结合物的量与反应物浓度有关。只有在抗原与抗体**分子比例合适**时才出现最强反应（等价带）。 |
| **可逆性** | 遵循生物大分子热动力学反应原则：$$ \frac{[Ab-Ag]}{[Ab]\cdot[Ag]} = \frac{k_1}{k_2} = K $$<br>其中 $K$ 为平衡常数，反映抗原抗体结合能力（亲和力）。 |

### 3. 常见的免疫分析方法分类
1. **免疫凝集**（Agglutination）
2. **免疫沉淀**（Precipitation）：环状沉淀试验、单向免疫扩散、双向免疫扩散、免疫电泳、火箭电泳
3. **酶联免疫分析技术**（ELISA）：直接法、间接法、夹心法
4. **免疫印迹**（Immunoblotting / Western Blot）

## 五、免疫凝集（Agglutination）

### 1. 定义
- 细菌、红细胞等**颗粒性抗原**与相应抗体特异结合后，在适量电解质存在下逐渐聚集，出现肉眼可见的凝集现象。
- **凝集原**（agglutinogen）：反应中的抗原；
- **凝集素**（agglutinin）：反应中的抗体。

### 2. 直接凝集反应（Direct Agglutination）
- **原理**：颗粒抗原（细菌、螺旋体、红细胞）在适当电解质参与下**直接与**相应抗体结合出现凝集。
- **常用方法**：
  - **玻片法**：定性试验，用已知抗体（诊断血清）与受检颗粒抗原各加一滴在玻片上混匀，数分钟后肉眼观察。**出现颗粒凝集为阳性**。
    - 应用：菌种诊断/分型、红细胞 **ABO 血型鉴定**。
  - **试管法**：半定量，常用于测定抗体效价。

### 3. 间接凝集反应（Indirect / Passive Agglutination）
- **原理**：将**可溶性抗原（或抗体）**先吸附于适当大小的颗粒性载体表面，再与相应抗体（或抗原）作用，在适宜电解质条件下出现特异性凝集。
- **特点**：敏感度高于沉淀反应，适用于各种抗体和可溶性抗原的检测，广泛应用于临床检验。
- **流程**：载体颗粒 + 可溶性抗原 → 致敏颗粒 + 抗体 → 凝集。

## 六、免疫印迹（Immunoblotting / Western Blotting）

### 1. 定义与原理
- 根据抗原抗体特异性结合，检测样品中某种蛋白的方法。
- **核心步骤**：
  1. **分离**：混合抗原样品在凝胶板上进行电泳（通常为 SDS-PAGE）分离；
  2. **转移**：取固定化基质膜（如 NC 膜）与凝胶相贴，在外力（电场力/吸附力）作用下，凝胶中的单一抗原组分转移到印迹纸上并固定化；
  3. **检测**：应用免疫酶探针或同位素探针等进行检测分析。

### 2. 详细操作流程
1. 蛋白质样品 **SDS-PAGE 电泳分离**（保持生物学活性和多肽类型不变）；
2. **转移到固相载体**（NC 膜/PVDF 膜），转移后的膜称为**印迹（Blot）**；
3. **封闭**：加入蛋白溶液（如脱脂奶粉/BSA）封闭剩余疏水结合点，防止非特异性结合；
4. 加入**一抗**（primary antibody）→ 形成抗原抗体复合物；
5. **洗涤**：洗去未结合的一抗；
6. 加入**标记的二抗**（secondary antibody，如 HRP/AP 标记）→ 形成复合物；
7. **显色/发光**：二抗与底物反应显色或化学发光；
8. **结果判读**：指示一抗位置 → 指示待研究蛋白质的位置。

### 3. 检测方法分类
| 方法 | 原理 |
|------|------|
| **直接法** | 酶直接标记一抗，一抗与膜上抗原结合后直接显色 |
| **间接法** | 酶标记二抗，二抗识别一抗，信号放大，更常用 |

### 4. 常用显色/检测系统
- **辣根过氧化物酶法（HRP）**
- **碱性磷酸酶法（AP）**
- **化学发光显色法**（灵敏度高，最常用）

## 七、标记免疫分析技术

### 1. 概述
- **标记免疫技术 = 免疫技术（抗原抗体特异结合）+ 标记技术（示踪物灵敏标记）**
- **主要特点**：高特异性、高灵敏度。

#### 技术分支
- **免疫组化技术**：组织化学定位
- **免疫测定技术**：
  - 放射免疫技术
  - 荧光免疫技术
  - **酶免疫技术**
  - **化学发光技术**
  - 金免疫技术

## 八、放射免疫技术（Radioimmunoassay, RIA）

### 1. 发展简史
- 1950s：Pressman & Eisen 用放射性碘标记抗原研究抗原-抗体反应；
- 1953-1956：Solomon Berson & Rosalyn Yalow 发现非标记抗原抑制标记抗原与抗体结合；
- 1960：创建**放射免疫分析法（RIA）**，用于测定胰岛素；
- 1977：Yalow 获诺贝尔生理学或医学奖（肽类激素的放射免疫测定）。

### 2. 技术分类与原理

#### （1）放射免疫分析（RIA）
- **原理**：**竞争性结合**。标记抗原（Ag\*）与反应系统中未标记抗原（Ag）**竞争结合**限量特异性抗体（Ab）。
- **条件**：Ab 限量，Ag\* 定量，Ag\* 和 Ag 的量大于 Ab 结合位点。
- **结果**：随着 Ag 增加，Ag\*-Ab 复合物（B）减少，游离 Ag\*（F）增加。
- **剂量反应曲线**：以未结合的 Ag\* 为 F，Ag\*-Ab 复合物为 B，则 **B/F 或 B/(B+F)** 与 Ag 的量变存在函数关系（**反比关系**）。

#### （2）免疫放射分析（IRMA）
- **原理**：**非竞争性结合**。以**过量标记抗体（Ab\*）**与抗原非竞争结合，采用固相免疫吸附载体分离游离和结合标记抗体。
- **类型**：
  - **单位点 IRMA**：过量标记抗体与抗原反应 → 固相抗原结合未结合的标记抗体 → 分离沉淀物，测定**上清液放射量**；
  - **双位点 IRMA（夹心法）**：固相抗体 + 抗原 + 过量标记抗体 → 形成固相抗体-抗原-标记抗体复合物 → 洗涤 → 测定**固相上放射性**。

### 3. RIA 与 IRMA 比较

| 比较项目 | RIA | IRMA |
|----------|-----|------|
| **标记物** | 抗原 | 抗体 |
| **原理** | 竞争性结合 | 非竞争结合 |
| **反应体系** | Ag\*、Ag、Ab | 固相 Ab、Ab\*、Ag |
| **反应动力学** | 慢 | 快 |
| **灵敏度** | 相对低 | 高 |
| **检测范围** | 窄 | 宽（1~2 个数量级） |
| **特异性** | 差（多克隆抗体 PcAb） | 优（单克隆抗体 McAb） |
| **标准曲线** | 结合率与测值成**反比** | 结合率与测值成**正比** |
| **待测抗原要求** | 大小分子均可 | 需两个抗原决定簇 |

### 4. 常用放射性核素
| 核素                  | 射线       | 半衰期    | 标记方法 | 特点               |
| ------------------- | -------- | ------ | ---- | ---------------- |
| **$\ce{ ^{125}I}$** | $\gamma$ | 60.2 d | 简单   | 活泼、设备低廉、测量简单，最常用 |
| **$\ce{ ^{3}H}$**   | $\beta$  | 12.3 y | 复杂   | 理化性差、设备昂贵、测量复杂   |

## 九、酶免疫分析法（Enzyme Immunoassay, EIA）

### 1. 均相酶免疫测定（EMIT）
- **全称**：酶扩大免疫测定技术（Enzyme-multiplied Immunoassay Technique）
- **原理**：酶标半抗原（小抗原）与待测半抗原竞争结合抗体。因抗原较小，酶与抗体接触紧密，**酶活性被抑制**；无需相分离，直接测定酶活性。
- **特点**：
  - 竞争性；
  - 均相（结合前后酶受抑制）；
  - 主要用于测定小分子抗原或半抗原。

### 2. 非均相酶免疫测定——ELISA

#### （1）基本原理
- 先将抗体或抗原**包被**到固相载体（聚苯乙烯微孔板）表面，保持免疫活性；
- 测定时，待检样本和酶标抗原/抗体按步骤与固相表面吸附的抗体/抗原反应；
- **洗涤**分离复合物和游离成分；
- 加入酶反应底物**显色**，根据颜色深浅（吸光度 A 值）进行定性或定量。

#### （2）基本操作流程（以间接法为例）
1. 包被抗原 → 2. 洗涤 → 3. 加待检抗体 → 4. 洗涤 → 5. 加酶标抗体 → 6. 洗涤 → 7. 加底物显色 → 8. 观察/测定结果。

#### （3）ELISA 的分类与原理

| 方法      | 原理简述                    | 应用场景                |
| ------- | ----------------------- | ------------------- |
| **直接法** | 固相抗原 + 酶标一抗 + 底物        | 快速，但灵敏度较低           |
| **间接法** | 固相抗原 + 待测一抗 + 酶标二抗 + 底物 | **测定抗体**最常用的方法，信号放大 |
| **夹心法** | 固相抗体 + 待测抗原 + 酶标抗体 + 底物 | **测定抗原**常用（需两个结合位点） |
| **竞争法** | 固相抗体 + 待测抗原与酶标抗原竞争 + 底物 | 测定小分子抗原             |

#### （4）常用底物
| 底物              | 酶   | 显色特点                       | 优缺点                    |
| --------------- | --- | -------------------------- | ---------------------- |
| **OPD**（邻苯二胺）   | HRP | 橙黄色 → 加酸终止后棕黄色，λmax=492 nm | 敏感，但稳定性差、易变色、**致癌性**   |
| **TMB**（四甲基联苯胺） | HRP | 蓝色 → 加硫酸终止后黄色，λmax=450 nm  | 稳定性好、无需避光、无致突变；水溶性相对较差 |

## 十、发光免疫分析法（Luminescence Immunoassay, LIA）

### 1. 发光的基本概念
- **发光**：分子或原子中的电子吸收能量后由基态跃迁到激发态，再返回基态时释放光子的过程。

#### 发光类型
| 类型 | 能量来源 | 典型实例 |
|------|----------|----------|
| **光照发光** | 短波长入射光照射 | 荧光素标记免疫分析 |
| **生物发光** | 荧光素酶催化，ATP 供能 | 萤火虫发光 |
| **化学发光** | 化学反应产生的能量 | 化学发光免疫分析 |

### 2. 化学发光免疫分析系统（CLIA）

#### （1）直接化学发光免疫分析
- **特点**：发光剂直接标记抗原或抗体，**无需酶催化**，直接参与发光反应。
- **常用发光剂——吖啶酯**：
  - 在碱性条件下被 H₂O₂ 氧化；
  - 发出波长 **470 nm** 的光；
  - 激发态产物 N-甲基吖啶酮为发光体；
  - **夹心法示例**：磁微粒-抗体 + 被测抗原 + 吖啶酯标记抗体 → 洗涤 → 加 H₂O₂（pH<10）→ 加碱（pH>10）→ **发光**。

#### （2）化学发光酶免疫分析（CLEIA）
- **原理**：用酶（HRP 或 ALP）标记抗原/抗体，免疫反应后形成固相包被抗体-待测抗原-酶标记抗体复合物，加入发光底物，酶催化分解底物发光。

##### ① HRP 标记的 CLEIA
- **底物**：**鲁米诺（Luminol）**及其衍生物 + H₂O₂
- **增强剂**：四苯硼钠、对碘苯酚、2-碘苯酚等（可显著增强发光信号）。
- **过程**：双抗体夹心复合物 + 增强剂 + 鲁米诺 + H₂O₂ → 鲁米诺发光。

##### ② ALP 标记的 CLEIA
- **底物**：**AMPPD**（1,2-二氧环乙烷衍生物，即 3-(2'-螺旋金刚烷)-4-甲氧基-4-(3"-磷酰氧基)苯-1,2-二氧杂环丁烷）
- **过程**：ALP 使 AMPPD 脱去磷酸根基团 → 产生金刚烷 + 酚盐中间体 → 发出稳定光信号。

#### （3）电化学发光免疫分析（ECLIA）
- **原理**：以电化学发光剂**三联吡啶钌 \[Ru(bpy)₃]²⁺** 标记抗体（抗原），以**三丙胺（TPA）**为电子供体，在电场中因电子转移而发生特异性化学发光反应（包含电化学和化学发光两个过程）。
- **发光波长**：**620 nm**。
- **电极反应**：
  - 阳极表面：\[Ru(bpy)₃]²⁺ 失去电子氧化为 \[Ru(bpy)₃]³⁺；
  - TPA 失去电子形成 TPA⁺•，再失去质子形成 TPA•；
  - TPA• 将电子传递给 \[Ru(bpy)₃]³⁺，形成激发态 \[Ru(bpy)₃]²⁺*；
  - 激发态返回基态时释放光子（620 nm）。

##### 链霉亲和素-生物素包被技术
- **应用**：广泛用于 ECLIA 的固相分离系统。
- **原理**：链霉亲和素（Streptavidin）与生物素（Biotin）具有极高亲和力；生物素可标记抗体、抗原、肽、核酸等；链霉亲和素包被于磁微粒表面，用于捕获生物素标记的分子。

##### ECLIA 仪器原理
- 磁微粒（包被抗体）与抗原、钌标记抗体形成复合物；
- 磁铁将复合物吸附至工作电极表面；
- 施加电压触发钌标记物发光；
- 光电倍增管检测光信号，信号强度与待测物浓度成正比。

## 十一、应用实例：禽流感病毒检测（NASBA + ECL）

### 1. 技术组合优势
- **快速**：恒温扩增 + 电化学发光，数小时内完成；
- **灵敏**：可检出极低载量病毒 RNA；
- **便携**：适合养殖场、口岸等现场检测；
- **可靠**：核酸扩增高灵敏度 + ECL 高特异性。

### 2. NASBA 技术（恒温 RNA 扩增）
- **本质**：恒温扩增技术（37~41℃），无需热循环仪。
- **核心酶系**：AMV 逆转录酶（AMV-RT）、RNase H、T7 RNA 聚合酶。
- **流程**：
  1. 引物结合模板 RNA，AMV-RT 合成 cDNA 第一链；
  2. RNase H 降解 RNA:cDNA 杂合链中的 RNA；
  3. 第二条引物结合 cDNA，AMV-RT 合成第二链 cDNA（含 T7 启动子）；
  4. T7 RNA 聚合酶以双链 DNA 为模板，大量合成 RNA 拷贝（10⁶~10⁹ 倍扩增）。
- **产物特点**：单链 RNA（非 DNA）。
- **优势**：恒温反应（设备要求低）、直接扩增 RNA（无需预先反转录）、扩增效率高。

### 3. 电化学发光（ECL）检测
- NASBA 扩增产物（RNA 单链）与**捕获探针**（结合磁珠）及**钌标记检测探针**杂交；
- 磁珠富集复合物到工作电极；
- 施加电压触发钌标记物发光，光信号强度与扩增产物量正相关。

### 4. NASBA vs. PCR（RT-PCR）性能比较

| 维度 | NASBA | PCR (RT-PCR) |
|------|-------|--------------|
| **反应温度** | 恒温（37~41℃），无需温控仪 | 变温循环（95℃/60℃/72℃），需热循环仪 |
| **模板** | 直接以 RNA 为模板，一步完成 | 需先反转录为 cDNA，再扩增 DNA |
| **速度** | 快（~90 分钟） | 相对慢（~2 小时） |
| **灵敏度** | 高（可检测低拷贝 RNA） | 高（灵敏度接近） |
| **设备依赖** | 低，适合现场/基层 | 高，必须配备 PCR 仪 |
| **产物类型** | 单链 RNA | 双链 DNA |
| **与 ECL 联用** | 产物为单链，可直接与磁珠探针杂交 | 产物为双链，需解旋得到单链才能杂交 |

- **结论**：在该应用场景下，NASBA 因其恒温、快速、对 RNA 直接扩增及产物单链特性，更适合与 ECL 联用进行现场快速检测；PCR 虽通用性更广，但设备要求高且需额外解旋步骤。

## 十二、关键知识点速记表

| 概念/技术 | 核心要点 |
|-----------|----------|
| **完全抗原** | 免疫原性 + 免疫反应性 |
| **半抗原** | 仅有免疫反应性，需载体赋予免疫原性 |
| **表位** | 抗原决定簇，TCR/BCR/抗体结合的基本单位 |
| **Ig 结构** | Y 形，2H+2L，V 区（N 端）+ C 区（C 端） |
| **抗原抗体反应特点** | 特异性、按比例、可逆性（$K$ 值） |
| **直接凝集** | 颗粒抗原 + 抗体 → 凝集（血型鉴定） |
| **间接凝集** | 可溶性抗原包被载体 + 抗体 → 凝集 |
| **Western Blot** | 电泳分离 → 转膜 → 封闭 → 一抗 → 二抗 → 显色 |
| **RIA** | 标记抗原，竞争性，限量抗体，结合率与测值**反比** |
| **IRMA** | 标记抗体，非竞争性，过量抗体，结合率与测值**正比** |
| **ELISA 间接法** | 测抗体最常用；夹心法测抗原最常用 |
| **ELISA 底物** | OPD（492 nm，致癌）、TMB（450 nm，常用） |
| **直接化学发光** | 吖啶酯标记，470 nm，无需酶催化 |
| **CLEIA (HRP)** | 鲁米诺 + H₂O₂ + 增强剂 |
| **CLEIA (ALP)** | AMPPD 底物，脱磷酸发光 |
| **ECLIA** | 三联吡啶钌 + TPA，620 nm，电极激发 |
| **NASBA** | 恒温 RNA 扩增，产物为单链 RNA，适合现场快检 |
