### 第1节 实验数据采集与整理
#### 1.1 数据采集
##### 动力学数据类型
任何测量，第一个任务是定义被测参量以及测量标度。研究化学反应动力学任何测量，第一个任务是定义被测参量以及测量标度。研究化学反应动力学也不例外。

考察一个抽象反应
$$a_{1}\text{A}_{1}+\dots+a_{i}\text{A}_{i} \xrightarrow[]{ T,P } b_{1}\text{B}_{1}+ \dots + b_{j}\text{B}_{j}$$
其反应进度的微分和各成分的摩尔数变化关系如下
$$\text{d}\xi= - \frac{\text{d}n_{\text{A}_{i}}}{a_{i}}=\dots=\frac{\text{d}n_{\text{B}_{j}}}{b_{j}} =\cdots$$
反应进度排除了计量系数影响，规定了反应方向，因此可定义反应速率
$$\mathcal{V}=\dfrac{ \text{d} \xi }{ \text{d} t } $$
习惯上，用体积摩尔浓度的变化来表示反应速率，给出另一定义
$$\mathcal{V}= \frac{1}{V}\dfrac{ \text{d} \xi }{ \text{d} t } $$
具体地，对上抽象反应有
$$\mathcal{V}= -\frac{1}{V} \dfrac{ \text{d} n_{\text{A}_{i}} }{a_{i} \text{d} t }=-\dfrac{ \text{d} [\text{A}_{i}] }{ a_{i}\text{d} t }= \dots=\dfrac{ \text{d} [\text{B}_{j}] }{b_{j} \text{d} t }=\cdots$$

##### 数据采集
化学动力学实验观测的核心是测定反应系统中物质的浓度。总的来说，好的观测方法要求
- **高时间分辨率**（比反应半衰期小至少一个数量级）
- **零扰动**（不对反应系统产生任何可察觉的扰动）
- **高化学分辨率**（测定不随系统化学反应进展或反应条件变化而不清）


高时间分辨的浓度序列
- 容量分析：称量法、压强测定法、体积测定法
- 光谱分析：原子光谱、分子光谱
#### 1.2 数据整理
##### 积分动力学方程
**积分动力学方程**是反应物或产物浓度对时间的函数关系。对参加反应的分子$i$（可以是反应物电子态或产物电子态的一个分子），相应反应的积分动力学方程为
$$[i]=f(t)$$
数学上，对$f(t)$在反应考察开始时刻$t_{1}$进行泰勒展开，也即多项式拟合。
以$t=0$为例，作麦克劳林展开
$$[i]=a_{0}+a_{1}t+a_{2}t^{2}+\cdots$$
显然，$[i]_{0}=a_{0}$，$\displaystyle{\left. \dfrac{ \text{d} [i] }{ \text{d}  t}\right|_{t=0}}=a_{1}$，等等。
##### 微分动力学方程
因为质量作用定律的简洁与清晰，人们总是试图用类似的幂函数来表达任意一个化学反应的反应速率，其对应的**幂函数微分动力学方程**的一般通式为
$$\dfrac{ \text{d} [\text{A}_{i}] }{ \text{d}t  }= \mathscr{k}\prod [\text A_{i}]^{\nu _{j}}$$
式中某反应物浓度的幂指数称为该反应物的**反应级数**，所有幂指数之和等于总反应级数。

对其变形积分，结果就等价于积分动力学方程。
$$\dfrac{ \text{d} [i] }{ \text{d} t } = f([\text{A}_{1}],\dots[\text{B}_{j}])\implies \int \frac{\text{d}[i]}{f([\text{A}_{1}],\dots[\text{B}_{j}])}=\int k\text{d}t$$

幂函数微分动力学方程涵盖了所有基元反应，因此尽管实际反应系统微分动力学过程并不多数符合幂函数，但其化学意义清晰，根据幂指数可区分反应级数，前已讨论。

然而，即使实验数据与某个给定级数的动力学方程符合很好，也无法确定该反应就是一个拥有该级数的基元反应。实验得到的只是一个**表观反应速率常数**。不过，如果数据没有吻合的给定低整级数动力学方程，则系统不可能是基元反应系统。
#### 1.3 级数确定反应的积分动力学方程
##### 一级反应积分动力学方程
用下面的抽象反应来研究一级反应的积分动力学方程。为方便，假定$t=0$时系统中反应物$\text{A}$的体积摩尔浓度等于$[\text{A}]_{0}$，产物体积摩尔浓度等于零。
$$\text{A}\xrightarrow[]{ \mathscr{k} } \text{P}$$
以反应物浓度变化表征反应速率，得到微分动力学方程。变量分离，两边同时积分
$$-\dfrac{ \text{d} [\text{A}] }{ \text{d} t } =\mathscr{k}[\text{A}]\implies \int _{[\text{A}]_{0}}^{[\text{A}]}\dfrac{ \text{d} [A] }{ [\text{A}] } = \int _{0}^{t}-\mathscr{k}\text{d}t$$
结果即反应物浓度的**一级积分动力学方程**，并得其**半衰期**
$$\boxed{ [\text{A}]= [\text{A}]_{0} e^{ -\mathscr{k}t } ,\quad  t_{\frac{1}{2}}= \frac{\ln 2}{\mathscr{k}} }$$
反应物衰变到初始浓度的1/e的时间称为反应物的**寿命**$\tau$，对一级反应
$$\tau =\frac{ \ln e}{\mathscr{k}}=\frac{1}{\mathscr{k}}\implies \mathscr{k}\tau=1$$
##### 高级反应积分动力学方程
同上得到微分动力学方程，变量分离并作积分
$$-\dfrac{ \text{d} [\text{A}_{i}] }{ \text{d} t } =\mathscr{k}[\text{A}_{i}]^{\nu _{i}}\implies \int _{[\text{A}]_{0}}^{[\text{A}]}\dfrac{ \text{d} [\text{A}_{i}] }{ [\text{A}_{i}]^{\nu _{i}} } = \int _{0}^{t}-\mathscr{k}\text{d}t$$
结果即**高级反应的积分动力学方程**
$$\boxed{ \frac{1}{[\text{A}_{i}]^{\nu _{i}-1}}- \frac{1}{ [\text{A}_{i}]_{0}^{\nu _{i}-1}} = (\nu _{i}-1)\mathscr{k}t,\quad \nu _{i}\geq  2}$$
#### 1.4 反应级数$\nu_{0}$
对微分动力学方程求微分得
$$\ln \mathcal{V} = \ln \mathcal{k} + \sum _{i}\nu _{i}\ln [\text{A}_{i}]\xlongequal[]{ 范托夫公式 } \ln A - \frac{E_{a}}{RT}+\sum _{i}\nu _{i}\ln [\text{A}_{i}]$$
上式中的每指数$\nu _{i}$为指定组分的**表观反应级数**，一般情况下不会等于反应的计量系数，甚至可能是小数、负数，也可能是零。
该式揭示，由$\ln \mathcal{V}- \ln[\text{A}_{i}]$曲线斜率得到$\nu _{i}$；由$\ln \mathcal{V}-\dfrac{1}{RT}$曲线斜率得到**表观活化能**$E_{a}$。
### 第2节 化学动力学平衡
第十五章中，我们将化学平衡与化学动力学统一于一个理论框架：**局域平衡态理论**
- 化学平衡态实际上是局域平衡态；
- 而动力学则是系统从一给定稳定电子态向另一稳定电子态（稳定电子态是一种特殊的局域平衡态）过渡的过程，终点是化学平衡态。

正逆反应各自的速率常数并不完全取决于反应物和产物电子态的$\Delta _{r(+)}G^{o}$，而还与上行和下行特征时间有关。因此，即使正逆反应对都是基元反应，也无法由正逆反应对速率常数之比求相应的化学热力学平衡常数。
#### 2.1 一级正逆反应对
考虑下面正逆反应对，其正逆反应都是一级反应。$t=0$时，$\text{A}$浓度为$[\text{A}]_{0}$，$\text{P}$浓度为零。则可列出元素守恒和正逆反应对的总微分动力学方程
$$\ce{ A <=>[\mathscr{k}_{正}][\mathscr{k_{逆}}] P}\qquad \begin{cases}[\text{P}]=[\text{A}]_{0}- [\text{A}] \\ \dfrac{ \text{d} [\text{A}] }{ \text{d} t } = \mathscr{k}_{逆}[\text{P}]-\mathscr{k}_{正}[\text{A}]\\ \dfrac{ \text{d} [\text{P}] }{ \text{d}  t} = \mathscr{k}_{正}[\text{A}]-\mathscr{k}_{逆}[\text{P}]\end{cases}$$
若系统满足**正、逆反应速率相等**，则称系统处于**化学动力学平衡态**，由此可定义**化学动力学浓度平衡常数**，其等于正逆反应速率常数之比。
$$\dfrac{ \text{d} [\text{A}] }{ \text{d} t } =\dfrac{ \text{d} [\text{P}] }{ \text{d} t } \implies  \left.\frac{[\text{P}]}{[\text{A}]}\right|_{动力学平衡态}=\frac{\mathscr{k_{正}}}{\mathscr{k_{逆}}}\equiv K_{[i](动)}$$
回顾前面内容，系统在反应物和产物**吉布斯自由能级上平衡分布**达成**化学热力学平衡**。

将局域平衡态动力学基本公式代入化学动力学浓度平衡常数式，变形即得**化学动力学平衡态和热力学平衡态的关系**
$$\begin{aligned}K_{[i](动)}&= \frac{1}{(t^{o}_{上}t^{o}_{下})_{正}}\exp \left(  -\frac{\Delta _{r(+)}G_{垒(正)}}{RT} \right)\Big/\frac{1}{(t^{o}_{上}t^{o}_{下})_{逆}}\exp \left(  -\frac{\Delta _{r(+)}G_{垒(逆)}}{RT} \right) \\
& = \frac{(t^{o}_{上}t^{o}_{下})_{逆}}{(t^{o}_{上}t^{o}_{下})_{正}} \exp \left(  - \frac{\Delta _{r(+)}G^{o}}{RT} \right) = \frac{(t^{o}_{上}t^{o}_{下})_{逆}}{(t^{o}_{上}t^{o}_{下})_{正}}\cdot K_{[i]}\end{aligned} $$
$\displaystyle{\frac{(t^{o}_{上}t^{o}_{下})_{逆}}{(t^{o}_{上}t^{o}_{下})_{正}}}$往往达到数个数量级，因此只有在特殊情况下，才有$K_{[i](动)}=K_{[i]}$。

对于正逆反应都是基元反应的情况，上式定量给出了两种平衡态的本质差别。
- 热力学平衡态只考虑两个稳定电子态之间$\Delta _{r(+)}G^{o}$或定温定压下系统和环境总熵的差别，系统的最终平衡态等价于在两个吉布斯自由能能级上的最概然分布；
- 动力学平衡态则还考虑了系统在两个吉布斯自由能能级间转换的**时间域因子**，即认为系统越过垒态的时间域概率具有**明显方向性**。
因此，化学动力学平衡态本质上是基于局域平衡态热力学的含时的化学平衡态，同时考虑了各稳定电子态出现的概率和稳定电子态之间演化过程的时域概率。

一些传统上被归属于热力学平衡态的特点实际上是动力学平衡态的特征。
- 边界条件不变，系统只能围绕动力学平衡态涨落，而不可能自发离开该状态，化学动力学平衡态表现为动态平衡，其浓度积满足$K_{[i](动)}$；
- 改变边界条件（如添加某种分子），系统偏离目前的动力学平衡态，通过调整系统内反应物和产物的比例最终达到新的动力学平衡态，其浓度积依然满足$K_{[i](动)}$。

系统达到$K_{[i]}\neq K_{[i](动)}$状态时，正反应速率和逆反应速率不相等，**净反应速率不为零**。这表明，热力学平衡态实际上不是一个稳定态，而会进一步进行直到动力学平衡态。

> [!error] 一身冷汗
> 对于均相溶液中任意反应，$K_{[i]}$定义的化学热力学平衡不可到达，只存在于经典热力学理论中；只有$K_{[i](动)}$定义的化学动力学平衡才是系统可实现的平衡。

回到一级正逆反应对本身，将元素守恒代入微分动力学方程，变量分离
$$\begin{aligned}\dfrac{ \text{d} [\text{A}] }{ \text{d} t } =\mathscr{k}_{逆}[\text{P}]-\mathscr{k}_{正}[\text{A}]=\mathscr{k}_{逆}[\text{A}]_{0} - (\mathscr{k}_{正}+\mathscr{k}_{逆})[\text{A}]\\\implies \frac{\text{d}[\text{A}]}{[\text{A}]- \dfrac{\mathscr{k}_{逆}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0}}=-(\mathscr{k}_{正}+\mathscr{k}_{逆})\text{d}t\end{aligned}$$
对上式左右积分即解得$[\text{A}]$的积分动力学方程，由元素守恒即得$[\text{P}]$的积分动力学方程。
$$\begin{aligned}&[\text{A}]= \dfrac{\mathscr{k}_{正}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0} e^{ -(\mathscr{k}_{正}+\mathscr{k}_{逆})t} +\dfrac{\mathscr{k}_{逆}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0}
\\& [\text{P}]=\dfrac{\mathscr{k}_{正}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0} \left[ 1-e^{ -(\mathscr{k}_{正}+\mathscr{k}_{逆})t} \right] \end{aligned}  $$
比较一级正逆反应对和一个单向一级反应，反应物浓度和产物浓度式多了一个与$\mathscr{k},[\text{A}_{0}]$相关的常数项。随着$t$增大，反应物浓度和产物浓度均有一个不同于单向反应的极限值。
$$[\text{A}]_{\infty}= \frac{\mathscr{k}_{逆}}{\mathscr{k}_{正}+\mathscr{k}_{逆}} [\text{A}]_{0},\quad [\text{P}]_{\infty}= \frac{\mathscr{k}_{正}}{\mathscr{k}_{正}+\mathscr{k}_{逆}} [\text{A}]_{0}$$
产物与反应物渐近线浓度之比等于正反应与逆反应的速率常数之比。对一级正逆反应对，也就是化学动力学平衡常数。

由$[\text{A}]$表达式，也可以求出反应物的**化学平衡时间常数**。
- 化学平衡时间常数等于**产物浓度从零达到平衡浓度一半**所需的时间。对于一个化学平衡，其时间常数测定的起始条件是系统只含有反应物，而产物的初始浓度等于零。
$$\frac{[\text{P}]_{\infty}}{2}=\dfrac{\mathscr{k}_{正}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0} \left[ 1-e^{ -(\mathscr{k}_{正}+\mathscr{k}_{逆})\tau _{平衡}} \right] \implies  \boxed{ \tau _{平衡}=\frac{\ln 2}{\mathscr{k}_{正}+\mathscr{k}_{逆}}}$$
对一级反应，求反应物浓度从初始值降低到初始值与平衡浓度平均值所需时间结果相同。此式表明，**一级正逆反应对的化学平衡时间常数反比于正反应和逆反应速率常数之和**。

对一般正逆反应对（正反应与逆反应都有**确定级数和速率常数**的反应），可由下面公式大致判断化学平衡时间常数
$$\tau _{平衡}\propto \frac{1}{\mathscr{k}_{正}+\mathscr{k}_{逆}}$$
如果正反应或逆反应没有明确级数，无法给出明确反应速率常数，此式不适用，只能依照实验方法来确定一个正逆反应对的化学平衡时间常数。这不是正逆反应对动力学的特质，而是积分动力学方程求分析解的普遍数学困难。

特别补充，可求出反应物的**寿命**
$$\frac{[\text{P}]_{\infty}}{e}=\dfrac{\mathscr{k}_{正}}{\mathscr{k}_{正}+\mathscr{k}_{逆}}[\text{A}]_{0} \left[ 1-e^{ -(\mathscr{k}_{正}+\mathscr{k}_{逆})t} \right] \implies  \tau=\frac{1}{\mathscr{k}_{正}+\mathscr{k}_{逆}}$$
由其形式上的简便，在后面反应因子式中使用寿命。
#### 2.2 复杂反应
对如下复杂抽象反应
$$\sum _{i}a_{i}\text{A}_{i}\ce{<=>[\mathscr{k}_{1}][\mathscr{k}'_{1}] } \sum_{j}b_{j}\text{B}_{j}\ce{<=>[\mathscr{k}_{2}][\mathscr{k}'_{2}] } \sum _{l}c_{l}\text{C}_{l}\ce{<=>[\mathscr{k}_{3}][\mathscr{k}'_{3}] }\sum_{m}d_{m}\text{D}_{m}$$
上面$K_{[i](动)}$与$K_{[i]}$的定量式不再成立，但定性关系仍适用，同时容易证明，定量式对于其中的任意一对正逆基元反应对成立。

对多步正逆反应对，各正逆基元反应对必定同时达到动力学平衡，即动力学平衡条件为
$$0=\dfrac{ \text{d} [\text{A}]_{i} }{ \text{d} t } =\dfrac{ \text{d} [\text{B}]_{j} }{ \text{d} t } =\dfrac{ \text{d} [\text{C}]_{l} }{ \text{d} t } =\dfrac{ \text{d} [\text{D}]_{m} }{ \text{d} t } $$
这一平衡称为**精细平衡原理**。文献上通常将其归结于化学热力学平衡，但我们已分析，精细平衡原理基于化学动力学平衡，与化学热力学平衡无关。
#### 2.3 反应因子
我们已讨论，**反应因子**实际上等于**化学动力学平衡常数**。引入**化学平衡时间常数**后，可以将反应因子扩展到含时的形式。这由积分动力学方程实现。
以一级正逆反应对为例，有
$$\frac{\mathcal{P}_{产物}}{\mathcal{P}_{反应物}}\equiv \frac{[\text{P}]}{[\text{A}]}=\frac{[\text{P}]_{\infty} \left( 1-e^{ -t/\tau} \right) }{[\text{P}]_{\infty} e^{ -t/\tau}  +[\text{A}]_{\infty}}= \frac{1- e^{-t/\tau}}{e^{-t/\tau} + 1/K_{[i](动)}}$$
上式两个浓度项不要求平衡，因此反应因子不再总是等于浓度化学平衡常数，这一步相当于给出**反应因子**正式定义。作为对比，第十三章讨论的反应因子只是**极限反应因子**。
$$\lim_{ t \to \infty } \frac{\mathcal{P}_{产物}}{\mathcal{P}_{反应物}}=\lim_{ t \to \infty } \frac{1- e^{-t/\tau}}{e^{-t/\tau} + 1/K_{[i](动)}}=K_{[i](动)}$$

引入时间常数，明确该过程是否会在宏观时间内发生，以及发生的相对快慢。同时，反应因子可以正确衡量一个正逆反应对在某一时刻是否到达其化学动力学平衡态。
- 例如，对于金刚石与石墨间的变化过程，传统平衡常数给出该过程一定会发生，但反应因子则会给出否定的结果。这是因为，该平衡在常温常压下的**时间常数**（可以通过对相应正逆反应对的两个速率常数的实验或计算来确定）**无限大**。因此，由上式，其对应的反应因子等于零，等价于平衡在常温常压下无法到达。

上面讨论了一级正逆反应对。原则上，对具体的一般非一级正逆反应对，应当有
$$\frac{\mathcal{P}_{产物}}{\mathcal{P}_{反应物}}=f\left( \frac{t}{\tau},K_{[i](动)} \right),\quad \lim_{ t/\tau \to \infty } \frac{\mathcal{P}_{产物}}{\mathcal{P}_{反应物}}=K_{[i](动)}$$
此式表明，无穷长时间下，任一正逆反应对的极限反应因子不趋于$K_{[i]}$，而是趋于$K_{[i](动)}$。这反映了可逆过程热力学宏观状态的本质：各宏观状态无论权重大小，其对应微观结构出现概率相等且并无先后顺序，即各状态实际上总是共存。
### 第3节 复杂反应的动力学方程
基元反应少见，尤其是溶液反应。下面将对复杂反应的实验研究做一些基本探讨。
一般地，相关内容属于反应机理研究的范畴：确定一个反应系统所涉及的所有稳定电子态与吉布斯自由能垒态（包括吉布斯自由能垒态的组成、结构和吉布斯自由能垒高度）。

研究反应机理，首先需要完成复杂反应的产物和中间产物的监测，此后就是对所得实验数据进行定量分析，以期将化学物质间的转换关系建立起来。
实验数据分析包括两条主要途径：
- **微分动力学方程**：包括确定该反应系统中涉及的所有稳定电子态及各稳定电子态之间的变化关系，即基元反应。确定基元反应后，就可写出一系列微分动力学方程。对于复杂反应，微分动力学方程可能太复杂，致使其参数不再具有十分明确意义。
- **积分动力学方程**：如果能够从理论上解得积分动力学方程即反应物或产物浓度随时间变化的函数关系，则可反过来检验反应机理是否恰当。这是本节讨论的内容。

复杂反应主要包括多步反应和竞争反应。竞争反应在第14章基本上处理完毕。本节将集中探讨处理多步反应动力学方程的手段。多数情况下，复杂反应的微分动力学方程难以精确求得分析解。下面探讨几种常见近似方法，以求给出微分动力学方程的**近似分析解**。
#### 3.1 决速步骤近似
对于一个多步反应，几乎不可能每步反应速率都相等（速率常数相等）。
$$\ce{ A_{1} + \dots+A_{$i$} ->[\mathscr{k}_{1}]  I_{1} ->[\mathscr{k}_{2}] I_{2} ->  \dots ->[\mathscr{k}_{$i$}]  I_{$i$} \to \cdots} $$
如果其中某步反应速率特别慢，那么整个反应速率将由这一步反应决定，称其为**决速步骤**。**用决速步骤代表整个反应速率的方法，就是决速步骤近似**。
$$\text{If}\quad \mathscr{k}_{i}\ll \min(\mathscr{k}_{1},\mathscr{k}_{2},\dots,\mathscr{k}_{i-1},\mathscr{k}_{i+1},\dots,\mathscr{k}_{f}),\quad \text{then} \quad \text{Rxn}\approx \ce{ I_{$i$}->[\mathscr{k}_{$i$}]I_{$i+1$}}$$
纯理论上，如果多步反应中某步基元反应的吉布斯自由能垒远高于其他基元反应，而反应综合特征时间差别不是非常大，那么，该步基元反应就可能是整个反应的决速基元反应。
#### 3.2 前平衡近似
若多步反应中某步反应，尤其是第一步反应，是一个正逆反应对，某些特定条件下，该正逆反应对可以处理为化学动力学平衡。若为第一步反应，则反应物和第一步的中间产物在整个反应发动起来前就可处理为动力学平衡态，等价于正逆反应速率相等，故称**前平衡近似**。

用下面的抽象反应讨论前平衡近似。假定初始浓度$\text{[A]}_{0}=[\text{B}]_{0}$，其他物质浓度为0。
$$\ce{ A + B <=>[\mathscr{k}_{1}][\mathscr{k}'_{1}] I ->[\mathscr{k}_{2}] P}$$
若第一步平衡的时间常数$\tau _{平衡,1}\ll t_{\frac{1}{2},2}$明显小于第二步反应的半衰期，则第一步将在第二步反应明显开始前达成平衡，能在极短时间内补充中间产物消耗，维持第一步前平衡。将其表达式代入，即要求**正逆反应速率常数之和要明显大于第二步反应的速率常数**。
$$\frac{\ln 2}{\mathscr{k}_{1}+ \mathscr{k}'_{1}}=\tau _{平衡,1}\ll t_{\frac{1}{2},2} =\frac{\ln 2}{\mathscr{k}_{2}}\implies \mathscr{k}_{2}\ll \mathscr{k}_{1}+ \mathscr{k}'_{1}$$
由前平衡近似，即有
$$\frac{[\text{I}]}{[\text{A}][\text{B}]}=\frac{[\text{I}]}{[\text{A}]^{2}} \approx \frac{\mathscr{k}_{1}}{\mathscr{k}'_{1}}\implies [\text{I}]= \frac{\mathscr{k}_{1}}{\mathscr{k}'_{1}}[\text{A}]^{2}$$
将上结果代入终产物的微分动力学方程有
$$\dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\mathscr{k}_{2}[\text{I}]=\frac{\mathscr{k}_{1}\mathscr{k}_{2}}{\mathscr{k}'_{1}}[\text{A}]^{2}$$
又由元素守恒，对式左右对$t$求导，代入上结果有
$$\begin{align}[\text{A}]_0=[\text{A}] + [\text{I}]+[\text{P}]\implies 0&=\dfrac{ \text{d} [\text{A}] }{ \text{d} t }+\dfrac{ \text{d} [\text{I}] }{ \text{d} t } +\dfrac{ \text{d} [\text{P}] }{ \text{d} t } \\
& =\dfrac{ \text{d} [\text{A}] }{ \text{d} t } \left(1+ 2\frac{\mathscr{k}_{1}}{\mathscr{k}'_{1}}[\text{A}] \right) + \frac{\mathscr{k}_{1}\mathscr{k}_{2}}{\mathscr{k}'_{1}}[\text{A}]^{2}\end{align}$$
对此微分方程积分求解，即得积分动力学方程。这一结果只特定对符合上抽象反应的复杂反应有意义，对其他类型的复杂反应可能完全不适用，但前平衡近似判据与思路相同。

> [!quote] 一级基元正逆反应对
> $$\ce{ A <=>[\mathscr{k}_{1}][\mathscr{k}'_{1}] I ->[\mathscr{k}_{2}] P}$$
> 分析思路相同，同样由前平衡近似判据有
> $$\begin{cases}前平衡近似 &\dfrac{[\text{I}]}{[\text{A}]} \approx \dfrac{\mathscr{k}_{1}}{\mathscr{k}'_{1}} \\ 微分动力学方程 & \dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\mathscr{k}_{2}[\text{I}]  \\ 元素守恒 & [\text{A}]_0=[\text{A}] + [\text{I}]+[\text{P}] \end{cases} \implies  \int _{[\text{A}]_{0}}^{[\text{A}]}\dfrac{ \text{d} [\text{A}] }{ [\text{A}] }=\int _{0}^{t} -\frac{\mathscr{k}_{1}\mathscr{k}_{2}}{\mathscr{k}'_{1}+\mathscr{k}_{1}} \text{d} t   $$
> 将其积分整理，得到$[\text{A}],[\text{P}]$的积分动力学方程。
> $$[\text{A}]=[\text{A}_{0}]\exp \left( -\frac{\mathscr{k}_{1}\mathscr{k}_{2}}{\mathscr{k}'_{1}+\mathscr{k}_{1}} t \right),\quad [\text{P}]=[\text{A}]_{0}\left[ 1- \frac{\mathscr{k}'_{1}+\mathscr{k}_{1}}{\mathscr{k}'_{1}} \exp \left( -\frac{\mathscr{k}_{1}\mathscr{k}_{2}}{\mathscr{k}'_{1}+\mathscr{k}_{1}} t \right)  \right]  $$
#### 3.3 稳态近似
多步反应序列中，中间产物在反应开始时形成较快。随反应进行其自身浓度提高，被进一步反应消耗的速率提高；同时由于反应物浓度降低，其生成速率降低。因此，反应开始后不久，一定条件下中间产物浓度可近似为常数，称为（中间产物）**稳态近似**。
用下面抽象反应研究稳态近似（只针对$\text{I}$）。假定初始浓度$\text{[A]}_{0}=[\text{B}]_{0}$，其他物质浓度为0。
$$\ce{ A + B ->[\mathscr{k}_{前}] I ->[\mathscr{k}_{后}] P}$$
仅当**从反应物到中间产物的反应比中间产物后面的反应慢**时，后者反应速率会根据中间产物生成量而改变，使得中间产物浓度维持基本不变，即稳态近似。
$$\mathscr{k}_{前}<\mathscr{k}_{后}$$
此时，同上节分析方法列出方程组
$$\begin{cases}稳态近似 &\dfrac{ \text{d} [\text{I}] }{ \text{d} t }=\mathscr{k}_{前}[\text{A}]^{2}-\mathscr{k}_{后}[\text{I}]\approx 0 \implies [\text{I}]=\dfrac{\mathscr{k}_{前}}{\mathscr{k}_{后}}[\text{A}]^{2} \\
微分动力学方程 & \dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\mathscr{k}_{后}[\text{I}] = \mathscr{k}_{前}[\text{A}]^{2} \\ 元素守恒 & [\text{A}]_0=[\text{A}] + [\text{I}]+[\text{P}] \end{cases}  $$
对元素守恒式作微分，由稳态近似有
$$\dfrac{ \text{d} [\text{A}] }{ \text{d} t } +\dfrac{ \text{d} [\text{I}] }{ \text{d} t } + \dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\dfrac{ \text{d} [\text{A}] }{ \text{d} t } + \dfrac{ \text{d} [\text{P}] }{ \text{d} t }=0 $$
代入前两式，分离变量并整理积分得
$$\int _{[\text{A}]_{0}}^{[\text{A}]} \frac{\text{d}\text{A}}{[\text{A}]^{2}} =\int _{0}^{t}-\mathscr{k}_{前} \text{d}t \implies  [\text{A}] = \frac{[\text{A}]_{0}}{1+\mathscr{k}_{前}t[\text{A}]_{0}}$$
$$\begin{align} [\text{P}] &= [\text{A}]_{0}-[\text{A}] -[\text{I}]\\&= [\text{A}]_{0}- \frac{[\text{A}]_{0}}{1+\mathscr{k}_{前}t[\text{A}]_{0}} - \dfrac{\mathscr{k}_{前}}{\mathscr{k}_{后}}\left( \frac{[\text{A}]_{0}}{1+\mathscr{k}_{前}t[\text{A}]_{0}} \right)^{2} \end{align}$$
显然，稳态近似不适用于反应刚开始和即将结束的一小段时间。这表明，一个反应中间产物稳态浓度应当越低越好，否则整个稳态假定的适用时段将很短。上已解出$[\text{I}]$表达式
$$[\text{I}]=\dfrac{\mathscr{k}_{前}}{\mathscr{k}_{后}}\left( \frac{[\text{A}]_{0}}{1+\mathscr{k}_{前}t[\text{A}]_{0}} \right)^{2}$$
显然，如果$\mathscr{k}_{前}<\mathscr{k}_{后}$成立，除去反应尾声段，总能做到$[\text{I}]\ll[\text{A}]_{0}$。
#### 3.4 酶催化反应动力学
作为复杂反应动力学分析的一个实例，讨论酶的催化机理，具体分析其动力学。
尽管酶催化多种多样，但它们基本上拥有下面的共同特征：
1. 酶一般是蛋白质，常伴有其他分子作为辅酶，与反应物分子一起形成底物-酶络合物。
2. 底物-酶络合物结合一般不强。因此其形成过程更适合用一个正逆反应对来描述。
3. 底物-酶络合物转化为产物-酶络合物的步骤一般是整个酶催化的决速步。然后，产物与酶分离实现催化中心再生、产物释放。产物-酶络合物分解的逆过程也可发生，因此也应该当作可逆反应对来处理。
4. 底物浓度一定时，产物的生成初始速率正比于酶浓度。
5. 酶浓度一定时，如果底物浓度不是太高，那么产物生成初始速率正比于底物浓度。
6. 酶浓度一定时，如果底物浓度很高，那么产物生成初始速率与底物浓度无关，表现为一个极限速率 $\mathscr{V}_{极大}$，是准零级反应。

由上实验事实，写出催化理论基本模型机理，其已经满足特征1, 2, 3。
$$\ce{ S + E <=>[\mathscr{k}_{1}][\mathscr{k}'_{1}] ES ->[\mathscr{k}_{2}] EP <=>[\mathscr{k}_{3}][\mathscr{k}'_{3}]E + P}\tag{0}$$
下面进行定量推导，以得到特征4, 5, 6。

(1) 实验事实表明产物-酶络合物的分子结合相对于底物-酶络合物的结合更不稳定，**其$\mathscr{k}_{3}'$的形成过程忽略不计**，因此机理简化为下面形式。
- 对于不同的酶催化系统，这一简化条件不一定总满足。若底物和产物与酶的标准反应自由能相差不是特别大，产物的不断生成会对酶活性产生抑制，形成反馈机制。
$$\ce{ S + E <=>[\mathscr{k}_{1}][\mathscr{k}'_{1}] ES ->[\mathscr{k}_{2}] EP ->[\mathscr{k}_{3}] E + P}\tag{1}$$

(2) 比较后两步的稳定性，产物-酶络合物分解的活化吉布斯自由能应该非常小，同时刚从高能垒上下来的产物-酶络合物会拥有非常大的热能，因此$\mathscr{k}_{2}\ll \mathscr{k}_{3}$，可用**决速步骤近似**。
$$\dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\mathscr{k}_{3}[\text{EP}]=\mathscr{k}_{2}[\text{ES}] \tag{2}$$

目前流行的教科书基于**Michaelis-Menten 机理**，其没有考虑$\mathscr{k}_{3},\mathscr{k}'_{3}$步骤，与上面简化机理形式接近，再利用稳态近似得到结果。稳态近似的唯一适用中间产物就是$\text{ES}$，但其前提条件$\mathscr{k}_{前}<\mathscr{k}_{后}$无论对上式机理还是或者Michaelis-Menten 机理都难以满足。
- 具体地，底物和酶的络合应当相当快速，又上已得到$\mathscr{k}_{2}\ll \mathscr{k}_{3}$，不可能有$\mathscr{k}_{1}\ll \mathscr{k}_{2}$。
相反地，实际情况为 $\mathscr{k}_{1}\gg\mathscr{k}_{2}$。因此，考虑到$\mathscr{k}'_{1}$反应同样易于发生，第一个反应对应该满足前平衡近似，甚至是决速步骤近似（等价于系统快速全部生成$\text{ES}$），如下分析。

(3.1) $\mathscr{k}_{1}\gg\mathscr{k}_{2}$，$\mathscr{k}'_{1}>0$，则必然有$\mathscr{k}_{1}+ \mathscr{k}'_{1} > \mathscr{k}_{2}$，可用**前平衡近似**。
$$\begin{align}&前平衡近似 &&\frac{[\text{ES}]}{[\text{E}][\text{S}]}=\frac{\mathscr{k}_{1}}{\mathscr{k}'_{1}} \\
&微分动力学方程 && \mathscr{V} = \dfrac{ \text{d} [\text{P}] }{ \text{d} t }=\mathscr{k}_{3}[\text{EP}]\xlongequal[]{ 式(2) }\mathscr{k}_{2}[\text{ES}]  \\
& 元素守恒 && [\text{E}]_{0}= [\text{E}] + [\text{ES}] + [\text{EP}] \xlongequal[]{ \text{[EP]}\ll \text{[ES]} }[\text{E}] + [\text{ES}]  \end{align}$$
由此解得酶催化反应速率随底物浓度、酶总浓度变化的基本公式。
$$\boxed{ [\mathscr{V}]=\mathscr{k}_{2}[\text{ES}]= \frac{\mathscr{k}_{1}\mathscr{k}_{2}[\text{E}]_{0}[\text{S}]}{\mathscr{k}'_{1}+ \mathscr{k}_{1}[\text{S}]}}\tag{3}$$
这一公式与上特征4, 5, 6吻合良好。
- $\mathscr{V}\propto[\text{E}]_{0}$，符合特征4；
- ${[\text{E}]_{0}}$给定，$[\text{S}]$较小时有$\mathscr{k}'_{1}\gg \mathscr{k}_{1}[\text{S}]$，则有$\displaystyle{ [\mathscr{V}]\approx \frac{\mathscr{k}_{1}\mathscr{k}_{2}[\text{E}]_{0}}{\mathscr{k}'_{1}}\cdot [\text{S}]\propto [\text{S}]}$，符合特征5；
- ${[\text{E}]_{0}}$给定，$[\text{S}]$很大时有$\mathscr{k}'_{1}\ll \mathscr{k}_{1}[\text{S}]$，则有$\displaystyle{[\mathscr{V}]\approx\mathscr{k}_{2}[\text{E}]_{0}}$，符合特征6。

(3.2) 底物浓度远高于酶浓度的情况常见，此时可假定所有酶都以与底物结合形式存在于系统中。这一近似与**决速步骤近似**等价，即认为酶被快速且基本彻底地转化为结合酶的状态。
- 不过，这里陈述的近似是基于对平衡常数、底物浓度、速率常数等因素的综合评价，要比简单的决速步骤近似来得坚实一些。
在这一近似下，由式(2)进一步得到**极限速率**
$$\dfrac{ \text{d} [\text{P}] }{ \text{d} t } =\mathscr{k}_{3}[\text{EP}]=\mathscr{k}_{2}[\text{ES}]=\mathscr{k}_{2}[\text{E}]_{0}\equiv \mathscr{V}_{极大}$$
此式与式(3)在${[\text{E}]_{0}}$给定，$[\text{S}]$很大时的近似结果相同，同样符合特征6。

由此式积分进一步得到积分动力学方程
$$\int _{0}^{[\text{P}]}\text{d}[\text{P}]=\int _{0}^{t}\mathscr{k}_{2}[\text{E}]_{0}\text{d}t \implies [\text{P}] =\mathscr{k}_{2}[\text{E}]_{0}t$$
实验上，作出$[\text{P}]-t$关系并拟合，由斜率即可得反应速率常数$\mathscr{k}_{2}$。
此外，将式(3)重排得到$1/V-1/[\text{S}]$直线函数，由截距也可得$\mathscr{k}_{2}$，称为双倒数作图法。
$$\frac{1}{\mathscr{V}}=\frac{1}{\mathscr{k}_{2}[\text{E}]_{0}} + \frac{\mathscr{k}'_{1}}{\mathscr{k}_{1}\mathscr{k}_{2}[\text{E}]_{0}[\text{S}]}$$

至此，通过对酶催化的动力学分析，本节揭示复杂动力学分析不但可以对实验现象给出很好的解释，还能利用实验数据反过来确定相关的动力学速率常数。
酶催化动力学不容易得到幂函数形式，也不容易得到有积分解的微分动力学方程。即使如此，还是可通过不同的实验方法、理论分析得到各基元步骤的动力学速率常数。
