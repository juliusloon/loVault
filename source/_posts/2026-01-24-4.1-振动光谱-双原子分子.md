#### 双原子分子振动能级
分子运动：振动
波段：中红外，1-30 µm
样品：固体、液体、气体
转动光谱的局限性：
- 必须为气态
- 极性分子
##### 简谐振动与Hooke定理
胡克定理
$$F=-k(r-r_{e})=-kx$$
振动势能
$$V(x)=\frac{1}{2}kx^{2}$$
运动方程
$$F=\mu \frac{\text{d}^{2}}{\text{d}t^{2}}=-kx,\quad \mu=\frac{m_{1}m_{2}}{m_{1}+m_{2}} $$
简谐振子
$$x=A\sin(\omega t+\varphi),\quad \omega=\sqrt{ \frac{k}{\mu} }$$
##### 双原子势能曲线
![](Image1.png)
令$x=R-R_{e}$，则在$x=0$作泰勒展开
$$\begin{aligned}V(x)&=V(0)+\left(\frac{\text{d}V}{\text{d}x}\right)_{0}+\frac{1}{2}\left( \frac{\text{d}^{2}V}{\text{d}x^{2}}  \right)_{0}x^{2}+\dots \\ & \approx \frac{1}{2} \left( \frac{\text{d}^{2}V}{\text{d}x^{2}}  \right)_{0}x^{2}=\frac{1}{2}kx^{2} \qquad谐振子近似 \end{aligned}  $$
##### 振动能级
薛定谔方程：谐振势能下两个原子间的相对运动
$$\left( -\frac{\hbar^{2}}{2\mu}\frac{ \partial^{2} }{ \partial x^{2} } +\frac{1}{2}kx^{2} \right)\Psi=E\Psi$$
得**振动能级**
$$E_{v}=\left( v+\frac{1}{2} \right)\hbar\omega \quad\text{[J]},\quad \omega=\sqrt{ \frac{k}{\mu } }$$
其中**振动量子数** $v=0,1,2\dots$
转化为波数单位：
$$\tilde{G}_{v}=\left( v+\frac{1}{2} \right)\tilde{v} \quad [\text{cm}^{-1}],\quad \tilde{v}=\frac{1}{2\pi c}\sqrt{ \frac{k}{\mu} }$$
- **振动零点能**：在绝对零度时也有振动（不确定性原理）
$$E_{0}=\frac{1}{2}\hbar\omega$$
- 振动能级等间隔
$$\Delta E_{v}=\hbar\omega$$
##### 波函数
$$\psi _{v}(x)=N_{v}H_{v}(y)e^{ -y^{2}/2 },\quad y=\frac{x}{\alpha},\alpha=\left( \frac{\hbar^{2}}{mk_{f}} \right)^{1/4}$$
其中$H_{v}(y)$称为厄米多项式 the Hermite polynomials

#### 振动光谱选择定则
##### 振动能级跃迁偶极
$$\mu _{if}=\braket{ \psi _{v}'(x) | \vec{\mu}(x)|\psi _{v}(x) } $$
电偶极$\vec{\mu}$也为$x$的函数，在平衡位置0附近作泰勒展开
$$\mu(x)=\mu _{x=0}=\left( \frac{ \partial \mu }{ \partial x }  \right)_{0}x+\frac{1}{2}\left( \frac{ \partial^{2}\mu }{ \partial x^{2} } \right)_{0}x^{2}+o(x)$$
认为电偶极矩在平衡位置附近为$x$的线性函数
$$\begin{aligned}\mu _{if}&=\braket{ \psi _{v}'(x) | \mu_{0} +\left( \frac{ \partial \mu }{ \partial x } \right)_{0}x|\psi _{v}(x)} \\ &=\underbrace{ \braket{ \psi _{v}'(x) |\mu_{0}|\psi _{v}(x) }  }_{ 谐振近似下振动波函数正交\to 0 }+\underbrace{ \left( \frac{ \partial \mu }{ \partial x }  \right)_{0}\braket{ \psi _{v}'(x) | x|\psi _{v}(x) } }_{ 必须不为0 }\end{aligned}  $$
1: **电偶极矩大小随振动发生改变**，即
$$\left( \frac{ \partial \mu }{ \partial x }  \right)_{0}\neq 0$$
对同核双原子分子，
$$\vec{\mu}_{e}=0\to \frac{\text{d}\vec{\mu}}{\text{d}r}=0$$
对异核对称分子，
$$\vec{\mu}_{e}可能 \neq 0\to \frac{\text{d}\vec{\mu}}{\text{d}r}可能\neq0 $$
- 对称伸缩：O \=\=\= C \=\=\= O -> O \= C \= O -> O \=\=\= C \=\=\= O 非红外活性
- 非对称伸缩：O \=\=\= C \=\=\= O -> O \=\=\= C \= O -> O \= C \=\=\= O 红外活性
- 弯曲振动：O ↗ C ↖ O → O - C - O → O ↖ C ↗ O 红外活性
2: **相邻能级跃迁**，即
$$\braket{ v' | x | v } =\left( \frac{\hbar}{2m\omega} \right)^{1/2}(\sqrt{ v+1 }\delta _{v',v+1}+\sqrt{ v }\delta _{v',v-1})\neq 0 \to  \Delta v=\pm 1$$
振动光谱表现出来为单峰
- 室温下，$k_{B}T=200 \text{ cm}^{-1}$，大部分分子都处于基态$v=0$，主要跃迁来自$v=0\to1$，故表现为单个跃迁谱线
$$\tilde{G}(v)=\left( v+ \frac{1}{2} \right)\tilde{v}_{0}$$

#### 振动非谐性
上述推导均基于谐振子近似，但事实上仅在平衡位置附近的低能级振动满足简谐振子模型，在高能态位置则不满足，因此要做非谐修正，引入
##### 摩尔斯 Morse 势
更接近真实势能曲线
$$V(q)=hcD_{e}(1-e^{ -ax })^{2},\quad a=\sqrt{ \frac{k}{2hcD_{e}} }$$
其中$D_{e}$：势能曲线最小值对应的深度

> [!quote] 在$x=0$附近
> $$V(q)=hcD_{e}=[1-1+ax+o(x^2)]^{2}\to hcD_{e}\cdot a^{2}x^{2}=\frac{1}{2}kx^{2}$$

求解薛定谔方程得：
$$\begin{aligned}
&E_{v}=\left( v+\frac{1}{2} \right)\hbar\omega _{e}\overbrace{ -\left( v+\frac{1}{2} \right)^{2}\hbar\omega _{e}\chi _{e} }^{ 非谐修正 }\quad[\text{J}]
\\&\tilde{G}_{v}=\left( v+\frac{1}{2} \right)\tilde{v}_{e}\underbrace{ -\left( v+\frac{1}{2} \right)^{2}\tilde{v}_{e}\chi _{e} }\quad [\text{cm}^{-1}]
\end{aligned}$$
其中非谐常数
$$\chi _{e}=\frac{a^{2}\hbar}{2\mu\omega}=\frac{\tilde{v}}{4\tilde{D}_{e}}$$
![](Image9.png)
##### 摩尔斯势振动能级
$$\tilde{G}_{v}=\left( v+\frac{1}{2} \right)\tilde{v}_{e}-\left( v+\frac{1}{2} \right)^{2}\tilde{v}_{e}\chi _{e}\quad [\text{cm}^{-1}]$$
随着v增大，能级间隔变小，分子的**平衡位置也发生变化** $\leftrightarrow$ 对谐振近似，平衡位置不变

##### 摩尔斯势振动光谱跃迁
由于非谐性，跃迁可以不严格遵守$\Delta v=\pm 1$，即可以发生非相邻能级跃迁（分别称为第一、第二...倍频/泛频 overtone），但信号均弱很多
由于非谐性（各振动能级不等间隔），热带跃迁（非基带跃迁）和基带跃迁（$v=0$开始的跃迁）的谱线不再重合
![](Image11.png)
综上，在谐振子模型下的单峰$\tilde{v}_{0}$，考虑非谐性时会产生热带跃迁峰、二倍频、三倍频等其他峰

#### 振-转跃迁
##### 刚性转子-谐振子
哈密顿量（忽略振动对转动的影响）
$$\hat{\mathcal{H}}=\hat{H}_{\text{vib}}(R)+\hat{H}_{\text{rot}}(\theta,\varphi)$$
解得波函数
$$\psi=\psi _{\text{vib}}(R)\psi _{\text{rot}}(\theta,\varphi)$$
能量
$$E_{\text{vr}}=\left( v+\frac{1}{2} \right)\hbar\omega+hBJ(J+1)\quad [\text{J}]$$
振动能级上叠加转动能级
$$\tilde{S}_{v.J}=\tilde{G}_{v}+\tilde{F}_{J}=\left( v+\frac{1}{2} \right)\tilde{v}+J(J+1)\tilde{B}\quad [\text{cm}^{-1}]$$
其中$\tilde{v}\gg \tilde{B}$
##### 跃迁选择定则
$$\left( \frac{ \partial \mu }{ \partial q } \right) _{0}\neq 0,\quad \Delta v=\pm 1,\quad \Delta J=0,\pm 1,\quad \Delta M_{J}=0,\pm 1$$
\*对非零角动量（非满壳层）分子，如NO，可以有$\Delta J=0$
$$\begin{aligned}
&P分支\,(吸收)&&\Delta J=-1 &&\tilde{v}_{P}(J)=\tilde{S}(v+1,J-1)-\tilde{S}(v,J)=\tilde{v}-2\tilde{B}J
\\&Q分支 &&\Delta J=0 && \tilde{v}_{Q}(J)=\tilde{S}(v+1,J)-\tilde{S}(v,J)=\tilde{v}
\\&R分支&&\Delta J=+1&&\tilde{v}_{R}(J)=\tilde{S}(v+1,J+1)-\tilde{S}(v,J)=\tilde{v}+2\tilde{B}(J+1)
\end{aligned}$$![](Image16.png)
图中的谱线应当为等间隔 $2\tilde{B}$

##### 振转光谱（考虑振动非谐性）
振转耦合：振动非谐性对转动的影响
高振动能级（振动激发态） → 键长变长 → 转动惯量变大，转动常数变小
$$B=\frac{h}{8\pi^{2}I}\to B_{v=0}>B_{v=1}$$
$$\begin{aligned}
&P分支\,(吸收)&&\Delta J=-1 &&\tilde{v}_{P}(J)=\tilde{v}_{0}-J(\tilde{B}_{0}+\tilde{B}_{1})-J^{2}(\tilde{B}_{0}-\tilde{B}_{1})
\\&R分支&&\Delta J=+1&&\tilde{v}_{R}(J)=\tilde{v}_{0}+(J+1)(\tilde{B}_{0}+\tilde{B}_{1})-(J+1)^{2}(\tilde{B}_{0}-\tilde{B}_{1})
\end{aligned}$$
因此，J ↑，P分支间隔↑，R分支间隔↓，即从随着能量↑（波数↑），间隔↓
