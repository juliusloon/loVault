## 第一节 生物传感器概述与发展历程
### 一、核心发展里程碑（填空 / 选择高频考点，按时间线排序）
1. 1930 年：pH 玻璃电极问世，为电化学传感奠定基础
2. 1956 年：**Clark 氧电极**诞生，是电化学传感器的核心基石，为后续酶电极开发提供核心器件
3. 1962 年：首个酶电极（血液 pO2 传感器）问世，开启生物传感器时代
4. 1966 年：葡萄糖酶电极研发成功，成为商业化最成熟的生物传感器原型
5. 1969 年：电位型酶电极（尿酶固定在氨电极上测定尿素）开发完成
6. 1970 年：离子敏感场效应晶体管（ISFET）问世，推动传感器微型化
7. 1975 年：首个基于酶电极的葡萄糖测定仪商业化；首款 1μm 直径微电极研发成功
8. 1976 年：以葡萄糖酶电极为基础的首个人工肾脏落地
9. 1977 年：测抗原的免疫传感器、测 BOD 的微生物传感器问世，拓展生物传感应用场景
10. 1983 年：表面等离子体共振（SPR）生物传感器、压电晶体酶传感器诞生
11. 1984 年：介体酶电极（二茂铁）开发，解决酶与电极间电子传递效率问题
12. 1987 年：印刷血糖酶电极问世，推动家用血糖仪普及；《Biosensors》期刊创刊，1990 年更名为《Biosensors &amp; Bioelectronics》（领域顶刊）
13. 1990 年：瑞典 Pharmacia 公司推出首台商用 SPR 仪器 Biacore；首届世界生物传感器大会在新加坡召开
14. 2000 年后：纳米生物传感器快速发展，碳纳米管（CNTs）、量子点（QDs）、纳米颗粒（NPs）推动传感性能跃升
15. 2010 年后：免标记成像技术、可穿戴柔性传感、单分子检测技术成为前沿热点

## 第二节 生物传感器的基本概念与核心组成
### 一、生物传感器的权威定义（名词解释必考）
1. **《Biosensors》完整定义**：生物传感器是一类分析器件，它将一种生物材料（组织、微生物细胞、细胞器、细胞受体、酶、抗体、核酸等）、或生物衍生材料、或生物模拟材料，与物理化学传感器或传感微系统密切结合，实现分析功能；配套的换能器或微系统可以是光学、电化学、热学、压电或磁学类型。
2. **Turner 教授简化定义**：生物传感器是一种精致的分析器件，它结合一种生物的或生物衍生的敏感元件与一只理化换能器，能够产生间断或连续的数字电信号，信号强度与被分析物成比例。

> 生物传感器是将生物敏感元件（如酶、抗体、核酸、细胞等）与理化换能器（如电化学、光学、热学、压电等）紧密结合的分析器件，通过生物识别作用产生与待测物浓度成比例的电信号，实现定量检测。
### 二、生物传感器的核心组成（简答必考，各部分作用需掌握）
生物传感器核心由**生物识别元件、换能器**两大核心模块，配套**信号放大系统、数据处理系统**构成，核心流程：待测物→生物识别元件特异性识别→生物化学反应信号→换能器转换为可测理化信号→信号放大→数据处理输出结果。
#### 1. 生物识别元件（生物受体）
- 核心作用：生物传感器的关键核心元件，直接决定传感器的功能、选择性与检测质量，实现对待测物的特异性识别。
- 主要类型及特点：
    1. 酶：基于酶与底物的特异性催化作用，选择性高、响应快，是应用最广泛的识别元件
    2. 微生物 / 全细胞：基于微生物代谢活性，成本低、稳定性好，适用于环境 / 食品复杂体系检测
    3. 抗体 / 抗原：基于抗原 - 抗体免疫特异性结合，特异性极强，是免疫传感核心元件
    4. 核酸 / 适配体：基于碱基互补配对的核酸杂交作用，或适配体的靶标高特异性结合，选择性好、易合成修饰
    5. 组织 / 细胞器：基于天然组织的多酶体系协同作用，稳定性高、无需酶分离纯化
    6. 模拟酶：基于人工合成的仿生催化材料，成本低、稳定性强，克服天然酶易失活的缺陷
#### 2. 换能器（信号转换器）
- 核心作用：将生物识别反应产生的化学、物理、生物信息，定量转换为可测量的电信号、光信号、压电信号等，是连接生物识别与信号输出的桥梁。
- 生物反应与换能器的对应匹配（填空 / 选择高频考点）：

| 生物反应产生的信号变化    | 对应适配的换能器         |
| -------------- | ---------------- |
| 离子浓度变化         | 离子选择性电极          |
| 质子浓度（pH）变化     | 场效应晶体管、pH 电极     |
| 电阻 / 电导 / 阻抗变化 | 阻抗计、电导仪          |
| 气体分压变化         | 气敏电极             |
| 热焓 / 温度变化      | 热敏电阻、热电偶         |
| 光学 / 荧光 / 颜色变化 | 光纤、光敏管、荧光计、光子计数器 |
| 质量变化           | 压电晶体、微悬臂梁        |
| 震动频率 / 折射率变化   | 表面等离子体共振（SPR）器件  |
## 第三节 生物传感器的分类（选择 / 简答高频考点）
### 一、按传感器输出信号分类
| 传感器类型        | 分类依据                                    | 核心特点                               |
| ------------ | --------------------------------------- | ---------------------------------- |
| 生物亲和性传感器     | 被测物与分子识别元件上的敏感物质具有生物亲和作用，通过结合作用直接产生信号   | 无需催化反应，基于特异性结合，如免疫传感器、核酸杂交传感器      |
| 代谢型 / 催化型传感器 | 底物与识别元件的敏感物质发生催化反应，通过底物消耗或产物生成的信号变化实现检测 | 基于酶 / 微生物的催化作用，信号持续产生，如酶传感器、微生物传感器 |
### 二、按分子识别元件分类（最核心分类方式，简答必考）
1. 酶传感器：以酶为分子识别元件，基于酶对底物的特异性催化反应，是研究最成熟、商业化最广泛的类型
2. 微生物传感器：以完整微生物细胞为识别元件，基于微生物的代谢活性或酶活性实现检测
3. 组织传感器：以动植物组织切片为识别元件，基于组织内天然多酶体系的协同催化作用
4. 免疫传感器：以抗原 / 抗体为识别元件，基于免疫反应的高特异性实现检测
5. 核酸 / DNA 传感器：以单链核酸探针为识别元件，基于核酸碱基互补配对的杂交作用实现检测
### 三、按信号换能器类型分类
1. 电化学传感器：以电化学电极为换能器，基于电流、电位、阻抗等电化学信号变化，应用最广泛
2. 离子敏场效应传感器：以场效应晶体管（FET）为换能器，基于表面电荷变化调控沟道电流
3. 热敏电阻传感器：以热敏电阻为换能器，基于生物反应的热焓变化实现检测
4. 压电晶体传感器：以压电晶体为换能器，基于质量变化引发的共振频率偏移实现检测
5. 光电 / 光学生物传感器：以光电器件为换能器，基于光吸收、荧光、SPR 等光学信号变化
6. 声学传感器：以声学装置为换能器，基于声波频率 / 振幅变化实现检测
## 第四节 典型生物传感器实用技术（原理题 / 大题核心考点）
### 一、酶电极传感器
1. 核心结构：由 生物识别层（固定化酶）**和**电化学电极（转换器） 构成，同时具备识别被测物质、信号转换两大核心功能。
2. 标杆应用：葡萄糖传感器（血糖仪、连续血糖监测 CGM），是研究最早、开发最成熟、市场化最成功的生物传感器。
3. **核心检测原理（反应式必考）**：
    - 基于 Clark 型氧电极制备，采用葡萄糖氧化酶（GOD/GOx）作为识别元件，对葡萄糖具有特异性响应。
    - 酶催化主反应：$\ce{C6H12O6 + O2 ->[GOD] C6H12O7 + H2O2}$
    - 电化学检测机理：通过电极检测**氧的消耗**或**过氧化氢的生成**实现葡萄糖定量
        - 氧还原反应：$\ce{O2 + 4H+ + 4e- -> 2H2O}$
        - 过氧化氢氧化反应：$\ce{H2O2 -> O2 + 2H+ + 2e-}$
4. **核心公式（计算必考）**：
    1. Cottrell 方程（扩散控制的电流-时间关系）：$i = FnAC^b \left(\frac{D}{\pi t}\right)^{1/2}$
5. 核心结构组成：透气膜、固定化葡萄糖氧化酶层、聚碳酸酯选择性膜、铂工作电极、Ag/AgCl 参比电极。
6. 关键临床参考值（空腹血糖）：
    - 低血糖：<2.8 mM
    - 正常范围：3.9~6.1 mM
    - 糖尿病：>9.0 mM
7. 进阶应用：连续血糖监测（CGM），通过微针阵列传感器检测组织液中间质葡萄糖，实现血糖的实时、连续、微创监测。
### 二、微生物传感器
1. 核心类型及检测原理：

|类型|核心检测原理|
|---|---|
|酶活性测定型|以微生物体内酶的催化反应活性为指标，原理与酶传感器类似|
|呼吸活性测定型|以微生物的呼吸活性为指标，通过检测耗氧量或 CO₂生成量实现待测物定量|
|电极活性物质测定型|以微生物代谢产物（H₂、NH₃、H⁺等）为检测目标，通过对应电极实现定量|
2. 核心特点（与酶传感器对比，简答高频）：
    - 优势：微生物较酶更易获得、价格低廉；稳定性好，连续使用时间可达 1 个月左右
    - 劣势：响应时间更长（多数在 10 分钟左右）；特异性较酶传感器差
3. 典型应用：
    - 水体 BOD（生物需氧量）监测：核心指标，反映水中可生化降解有机物的污染程度
    - 微生物燃料电池（MFC）：基于电活性微生物催化有机物产电，可作为自供电的水污染实时监测传感器
    - 致病菌活菌检测：基于核酸适配体的阻抗传感器，可实现鼠伤寒沙门氏菌的高特异性、免标记检测，检测限低至 600 CFU/mL
    - 抗生素药敏试验（AST）：传统 AST 需 16-24 小时，基于生物传感的快速 AST 可在 8 小时内完成，显著降低脓毒症患者的死亡风险（每延误 1 小时死亡风险增加 7.6%）
### 三、免疫电极传感器
1. 定义：以免疫物质（抗原或抗体）作为敏感元件的电化学生物传感器，核心优势是基于抗原 - 抗体反应的超高特异性。
2. 核心分类及对比（简答高频）：
  
|类型|核心原理|特点|
|---|---|---|
|直接免疫电极|无需标记物，通过免疫反应引发的介电常数、电导率、膜电位、离子通透性等电化学 / 电学变化直接输出信号|优点：不需额外试剂、仪器要求简单、操作容易、响应快；缺点：灵敏度低，难以作为标准检测方法|
|间接免疫电极|需制备酶标抗体 / 抗原结合物，通过标记物将免疫反应的信号放大后间接检测，核心代表为酶联免疫吸附测定（ELISA）|优点：信号放大后灵敏度高、定量准确，是临床检测金标准；缺点：操作流程相对复杂、需标记试剂|
1. 进阶应用：
    - 纸基 ELISA：基于纤维素纸构建 96 孔板等效检测体系，成本低、便携、无需大型设备，可实现 HIV 抗体、兔 IgG 等目标物的高灵敏检测，阳性结果可实现 10 倍血清稀释后仍有效区分
    - 胶体金免疫层析试纸条：基于抗原 - 抗体免疫反应，快速、成本低，适用于现场快速筛查，缺点是灵敏度低、易受干扰
### 四、DNA / 核酸生物传感器
1. 定义：利用单链 DNA（ssDNA）或基因探针作为敏感元件固定在固体电极表面，结合可识别杂交信息的电活性杂交指示剂，共同构成的检测特定基因的装置。
2. 工作原理：利用固定在电极表面的特定序列 ssDNA 与溶液中的同源序列的特异分子杂交，形成双链 DNA（dsDNA）；通过杂交指示剂对 ssDNA 和 dsDNA 的识别差异，以电流响应信号的改变实现目标核酸的定量检测。
3. 核心分类：直接 DNA 传感、间接 DNA 传感。
4. 信号放大技术（解决低浓度核酸检测灵敏度问题）：
    - PCR（聚合酶链反应）：核酸体外扩增技术，通过变性 - 退火 - 延伸循环实现靶序列的指数级扩增
    - RCA（滚环扩增技术）：恒温核酸扩增技术，固相反应速率 9 个核苷酸 / 分钟，可实现微量 microRNA 的超灵敏检测，常与计时库伦法（CC）联用
5. DNA 折纸技术（前沿考点）：
    - 定义：以一根 DNA 长链作为主链，通过多条短链（订书钉链）引导主链折叠组装成预定的二维 / 三维纳米结构
    - 核心应用：优化 DNA 探针空间排布，增强检测信号；精准排布酶的位置，调控酶级联反应的间距，大幅提升反应效率；构建纳米级生物传感界面
6. 病毒检测对比（选择 / 简答高频）：

| 检测方法     | 核心原理              | 速度       | 成本  | 灵敏度     | 可靠性     |
| -------- | ----------------- | -------- | --- | ------- | ------- |
| 抗原试纸条    | 抗原 - 抗体免疫反应       | 快（15 分钟） | 低   | 较低，易受干扰 | 一般，适合初筛 |
| PCR 核酸检测 | 核酸逆转录 + 扩增 + 荧光定量 | 慢（数小时）   | 高   | 极高      | 高，确诊金标准 |
## 第五节 生物传感器核心检测技术（实验题 / 原理题 / 计算题核心考点）
### 一、电化学生物传感核心技术
#### 1. 电化学生物传感基础
- 传感界面构建：核心是将 DNA、多肽、抗体、适配体等识别探针固定在电极表面，实现对待测物（核酸、蛋白、细胞、细菌、代谢物、离子等）的特异性识别
- 核心信号类型：电流、电位、阻抗、电导率、电容、光电信号、电致化学发光信号
- 核心传感模式：
    1. 电流传感：基于酶催化反应的电子传递，通过介体提升电子传递效率，实现底物定量
    2. 电位传感：基于离子选择电极或场效应晶体管（FET），通过表面电荷变化引发电位 / 电流变化
    3. 光电 / 电致化学发光传感：基于光电转换材料或电发光基团标记，实现信号放大与高灵敏检测
- 器件发展方向：便携式、植入式、可穿戴集成电化学传感器件
#### 2. 计时库伦法（Chronocoulometry, CC）
- 定义：一种用于研究电极表面吸附现象，定量测定电活性物质 / 表面活性物质在电极表面吸附量的电化学分析法，核心是测量**电量与电解时间的关系**，而非电流 - 时间关系。
- **核心公式（计算必考）**：
    1. Cottrell 方程（扩散控制的电流-时间关系）：$\displaystyle{ i = FnAC^b \left(\frac{D}{\pi t}\right)^{1/2} }$
        - 各参数意义：F 为法拉第常数（96487 C/当量），n 为电极反应转移电子数，A 为电极面积，$C^b$ 为被测物本体浓度，D 为扩散系数，t 为电解时间
    2. 总电量公式：$\displaystyle{ Q = 2FnAC^b \left(\frac{Dt}{\pi}\right)^{1/2} + Q_c + Q_{ads} }$
        - 各参数意义：第一项为扩散控制的法拉第电量，$Q_c$ 为双电层电容电量，$Q_{ads}$ 为吸附反应物产生的法拉第电量
    3. DNA 表面密度计算公式：$\displaystyle{ \varGamma_{DNA} = \frac{\varGamma \cdot z}{m} \cdot N_A }$
        - 各参数意义：z 为反应物分子电荷数，m 为探针 DNA 的碱基数量，$N_A$ 为阿伏伽德罗常数
- 核心应用：金电极表面 DNA 固定化定量、DNA 杂交效率测定、核酸 / 蛋白的超灵敏定量、电极表面吸附行为研究、结合 RCA 实现 microRNA 的超灵敏检测
#### 3. 示差脉冲伏安法（Differential Pulse Voltammetry, DPV）
- 核心原理：通过在阶梯扫描电位上叠加等幅度的脉冲电压，消除背景充电电流的影响，大幅提升检测灵敏度
- 核心特点：灵敏度高、检出限低、分辨率好，适用于痕量生物分子的定量检测，是电化学传感最常用的定量方法之一
### 二、光学生物传感核心技术 - 表面等离子体共振（SPR）
#### 1. SPR 基础定义与发展
- 定义：基于表面等离子体共振原理，免标记、实时检测生物传感芯片上配体与分析物相互作用的技术，1983 年首次用于生物传感，1990 年首台商用仪器 Biacore 问世。
- 核心用途：实时分析 DNA - 蛋白、蛋白 - 蛋白、药物 - 蛋白、抗原 - 抗体、受体 - 配体等生物分子间的相互作用，广泛用于生命科学、药物研发、临床检测等领域。
#### 2. **SPR 核心原理（简答 / 原理题必考）**
利用 p 偏振光在玻璃与金属薄膜界面处发生全内反射时，渗透到金属薄膜内的消逝波，引发金属中的自由电子产生表面等离子体；当表面等离子体与消逝波的频率相等时，二者发生共振，界面全反射条件被破坏，呈现衰减全反射现象，反射光能量急剧下降，在反射光谱上出现共振峰；当紧靠金属薄膜表面的介质折射率发生变化时，共振峰的位置（共振角）会对应偏移，以此实现分子结合过程的实时监测。
#### 3. 关键影响因素与信号定量方式
- 影响 SPR 共振角的核心因素：入射光波长、金属种类、金属薄膜表面物质的介电系数（折射率）
- SPR 信号的 3 种定量方式：
    1. 在最低光强处读取共振角位移（商用 SPR 仪器主流方案）
    2. 固定角度，读取反射光强变化（SPR 成像常用）
    3. 白光入射，测量光谱吸收峰位移（局域 SPR/LSPR 常用）
#### 4. **生物分子相互作用动力学（计算 / 曲线分析必考）**
- 核心结合解离平衡：$[\mathrm{L}] + [\mathrm{A}] \xrightleftharpoons[k_d]{k_a} [\mathrm{LA}]$
    - L 为配体，A 为分析物，LA 为配体 - 分析物复合物
- 核心动力学参数：
  
| 参数            | 定义                        | 单位              | 生物意义                   | 典型生物体系数值范围                            |
| ------------- | ------------------------- | --------------- | ---------------------- | ------------------------------------- |
| $k_a$（结合速率常数） | 描述复合物 LA 的生成速率            | $M^{-1}·s^{-1}$ | $k_a$越大，分子结合速度越快       | $1×10^3 ～ 1×10^7 M^{-1}·s^{-1}$       |
| $k_d$（解离速率常数） | 描述复合物 LA 的解离稳定性           | $s^{-1}$        | $k_d$越小，复合物解离越慢，稳定性越强  | $1×10^{-1} ～ 1×10^{-6} s^{-1}$        |
| $K_D$（解离常数）   | 描述分子间结合的亲和力，$K_D=k_d/k_a$ | $M$             | $K_D$越小，分子间结合越紧密、亲和力越强 | 抗体 - 抗原：0.1~10 nM；链霉亲和素 - 生物素：1~10 pM |
- 典型体系K_D参考范围：
    1. 蛋白质 - 离子：μM 级别
    2. 蛋白质 - 蛋白质：低 μM 级别
    3. 蛋白质 - DNA：100 nM ~ 10 μM
    4. DNA-DNA：10 nM ~ 1 μM
    5. 抗体 - 抗原：0.1 ~ 10 nM
    6. 链霉亲和素 - 生物素：1~10 pM（已知最强的生物分子相互作用之一）
- SPR 动力学曲线解读：曲线分为**基线、结合相（Association）、解离相（Dissociation）、再生**四个阶段；结合相上升越快，k_a越大；解离相下降越快，k_d越大。
#### 5. SPR 仪器与芯片
- 仪器核心构成：光路系统、SPR 光学检测系统、传感器芯片、微流控流通池、液体进样系统、数据分析软件
- 芯片核心结构：玻璃基底、金膜、连接层、葡聚糖基质、羧基活性基团；通过 EDC/NHS 活化实现蛋白 / 抗体等配体的氨基偶联固定
- 微流控系统：核心为集成微流控卡盒（IFC），通常包含 4 个串联流通池，可同时完成样品检测与对照实验，流道体积仅 20~40 nL
#### 6. SPR 技术的优缺点（简答高频）
- 优点：待测物无需标记；适用于混浊、不透明、有色溶液体系；能实时、连续监测生物分子反应的动态过程；检测方便快捷；应用范围广
- 缺点：难以区分特异性结合与非特异性吸附；对温度、样品组成等环境干扰因素敏感
## 第六节 生物传感器前沿与进展（论述题 / 开放题核心考点）
### 一、单分子与单细胞传感器
#### 1. 单分子免疫检测技术（SiMoA，数字 ELISA）
- 核心原理：结合微流控与磁珠技术，在单磁珠上形成单分子免疫复合物，将其分散到飞升级别微孔中，通过酶促底物反应的荧光成像实现单分子数字化计数，将传统 ELISA 的模拟信号转换为数字信号。
- 核心性能突破：传统 ELISA 检测极限为 15 fM，SiMoA 检测极限低至 220 zM，灵敏度提升超过 6 个数量级，是目前灵敏度最高的蛋白检测技术之一。
- 典型应用：
    1. 肿瘤标志物超灵敏检测：前列腺特异性抗原（PSA）、肿瘤坏死因子 -$\alpha$（TNF-$\alpha$）
    2. 神经退行性疾病早期诊断：阿尔茨海默病核心标志物 $\beta$ 淀粉样蛋白、tau 蛋白的超灵敏检测，解决早期标志物浓度极低难以检测的痛点
    3. 低丰度细胞因子、外泌体蛋白的定量分析
#### 2. 单细胞传感器
- 核心代表：纳米线场效应晶体管（nanoFET）系列器件
    1. 3D nanoFET：尺寸可低至 18 nm，柔性好，可实现心肌细胞等活细胞的胞内电信号原位记录
    2. 分支细胞内纳米管 FET（BIT-FET）：针尖外径可低至 55 nm，可无损进入细胞内，实现心肌细胞动作电位的多路复用、长期稳定记录
    3. 超小 BIT-FET：直径 &lt; 10 nm，向单分子级电信号检测突破
- 核心优势：超高时空分辨率、无损细胞检测、可实现单细胞水平的原位、实时电生理与生物分子检测
### 二、免标记成像技术 - SPR 成像（SPRi）
1. 核心原理：分为干涉成像与散射成像两种模式，2020 年后散射型 SPR 成像首次实现单蛋白灵敏度检测
2. 核心特点：免标记、对表面物质变化超高灵敏度（倏逝场仅对金属表面 100 nm 内的物质 / 折射率变化有响应）、高时空分辨率（时间分辨率达微秒级，空间分辨率达光学衍射极限）
3. 典型应用：
    - 细胞成像：原位测量细胞膜蛋白 - 配体的分子互作动力学（目前唯一可在细胞尺度实现该检测的技术）、神经细胞电传导动态成像、细菌 - 抗生素相互作用、细胞 - 纳米塑料相互作用的原位监测
    - 单颗粒检测：单病毒、单外泌体、纳米塑料颗粒的免标记成像与定量
    - 单分子成像：单个蛋白分子的结合 / 解离动态过程实时监测
    - 生物传感阵列：高通量生物分子互作筛选
### 三、纳米生物传感器
1. 定义：纳米技术与生物传感技术的融合，利用纳米材料的小尺寸效应、高比表面积、优异的电子传导性能，大幅提升传感器的灵敏度、选择性与微型化水平。
2. 核心纳米材料：硅纳米线、碳纳米管、石墨烯、纳米线、量子点、金纳米颗粒、DNA 纳米结构等。
3. 标杆器件：硅纳米线（SiNW）FET 纳米传感器
    - 制备原理：基于蒸汽 - 液 - 固（VLS）生长法，可精准调控纳米线的直径、长度、掺杂类型与浓度
    - 传感原理：待测物与纳米线表面修饰的识别元件结合，引发表面电荷变化，进而调控纳米线沟道的电导，通过电导变化实现待测物的超灵敏、免标记、实时检测
    - 典型应用：pH 高灵敏检测、生物素 - 链霉亲和素的蛋白结合检测、单细胞电生理记录、核酸 / 肿瘤标志物超灵敏检测
4. 技术突破：弯折纳米线、3D 立体纳米探针、自立式纳米 FET，实现三维空间内细胞指定区域的靶向检测与记录
### 四、柔性电极与可穿戴 / 植入式生物传感器
1. 核心特点：柔性、便携、可穿戴 / 植入、无创 / 微创、实时原位连续监测、无线数据传输，适配居家健康管理、运动生理监测、慢性病长期管理等场景。
2. 典型应用：
    - 可穿戴汗液传感阵列：集成葡萄糖、乳酸、钠、钾、温度等多指标传感器，制备为智能腕带 / 头带，可实现运动过程中汗液成分的实时、原位、多路复用分析，数据无线传输至手机端
    - 纸基呼吸传感器：基于纤维素纸的吸湿 - 离子电导变化特性，嵌入口罩中实现呼吸频率、呼吸模式的实时监测，成本极低、便携性强
    - 植入式生物传感器：Neuralink 神经电极阵列、植入式连续血糖监测（CGM）设备、细胞内电信号记录纳米探针
    - 一次性纸基传感器：纸基 ELISA、致病菌快速检测试纸、环境污染物现场检测器件
