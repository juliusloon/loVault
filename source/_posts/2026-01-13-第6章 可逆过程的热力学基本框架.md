### 第1节 宏观自由度与基本变量
#### 1.1 宏观自由度
系统-环境相互作用：
$$\text{d}U=\text{d}q+\text{d}W=-T_{surr}\text{d}S_{surr}-P_{ext}\text{d}V$$
系统内部：对映两个外秉（外源）自由度 $(V,S)$
$$\begin{align}\text{d}U&=T\text{d}S-P\text{d}V=(\text{d}U)_{V,n}+(\text{d}U)_{S,n} &\impliedby U=f(V,S)\\\text{d}U&=\left( \frac{ \partial U }{ \partial S }  \right)_{V,n}\text{d}S+ \left( \frac{ \partial U }{ \partial V } \right)_{S,n}\text{d}V &\impliedby 数学\\&\implies T\equiv \left( \frac{ \partial U }{ \partial S }  \right)_{V,n},\quad P\equiv- \left( \frac{ \partial U }{ \partial V }  \right)_{S,n} \end{align} $$
因此，宏观自由度实际上已经给出温度和压强的定义。
实际上，$U$还与内部组分的内秉自由度有关，即$U=f(V,S,n_{1},n_{2},\dots,n_{c})$
因此，宏观自由度数
$$\boxed{ F=2+c}$$
其中$c$为组分数。

> [!quote] e.g. 理想气体（纯态）
> $$PV=nRT\implies  g=f(x,y,z), F=2+1=3$$

#### 1.2 基本自变量
外源自由度：$(T,S)$ - 传热；$(P,V)$ - 做功
内秉自由度：$(M_{i},n_{i})$ - 物质扩散
考虑**封闭系统**：$\text{d}n_{i}\equiv0$
$$\begin{align} 
&\text{d}U=T\text{d}S-P\text{d}V \qquad \qquad \qquad \qquad \qquad \qquad \qquad \qquad \qquad \implies & \left( \frac{ \partial U }{ \partial S }  \right)_{V,n}=T, \left( \frac{ \partial U }{ \partial V }  \right)_{S,n}=-P \\
&\text{d}H=\text{d}(U+PV)=T\text{d}S-P\text{d}V+P\text{d}V+V\text{d}P=T\text{d}S+V\text{d}P & \left( \frac{ \partial H }{ \partial S }  \right)_{P,n}=T, \left( \frac{ \partial H }{ \partial P }  \right)_{S,n}=V \\
&\text{d}A=\text{d}(U-TS)=T\text{d}S-P\text{d}V-T\text{d}S-S\text{d}T=-(S\text{d}T+P\text{d}V) & \left( \frac{ \partial A }{ \partial T }  \right)_{V,n}=-S,\left( \frac{ \partial A }{ \partial V }  \right)_{T,n}=-P \\
&\text{d}G=\text{d}(H-TS)=T\text{d}S+V\text{d}P-T\text{d}S-S\text{d}T=-(S\text{d}T-V\text{d}P) & \left( \frac{ \partial G }{ \partial T }  \right) _{P,n}=-S,\left( \frac{ \partial G }{ \partial P }  \right)_{T,n}=V
\end{align}$$
因此，这四个**因变量**均对应两个自由度**自变量**
$$\begin{align} 
U\to (V,S)  \\
H \to (P,S)  \\
A \to (V,T)  \\
G \to (P,T)
\end{align}$$
### 第2节 热力学基本方程
#### 2.1 热力学基本方程
$$\text{d}U=T\text{d}S-P\text{d}V$$
#### 2.2 麦克斯韦关系式
如果状态函数$B$可以用另外两个状态函数$(X,Y)$完全表达，那么$B$的两个交叉二阶导数相等
$$\frac{ \partial^{2}B }{ \partial X\partial Y }=\frac{ \partial^{2}B }{ \partial Y\partial X } ,\quad \left[ \frac{ \partial  }{ \partial Y } \left( \frac{ \partial B }{ \partial X }  \right)_{Y} \right]_{X}=\left[ \frac{ \partial  }{ \partial X } \left( \frac{ \partial B }{ \partial Y }  \right)_{X} \right]_{Y} $$
将其应用于四个能量类函数的变量方程，即可得到新关系式
$$\begin{align} U\implies  & \left( \frac{ \partial U }{ \partial S }  \right)_{V,n}=T, \left( \frac{ \partial U }{ \partial V }  \right)_{S,n}=-P & \implies \left( \frac{ \partial P }{ \partial S }  \right)_{V,n}=-\left( \frac{ \partial T }{ \partial V }  \right)_{S,n} \\
H\implies & \left( \frac{ \partial H }{ \partial S }  \right)_{P,n}=T, \left( \frac{ \partial H }{ \partial P }  \right)_{S,n}=V &\implies \left( \frac{ \partial V }{ \partial S }  \right)_{P,n}=\left( \frac{ \partial T }{ \partial P }  \right)_{S,n} \\
A \implies  & \left( \frac{ \partial A }{ \partial T }  \right)_{V,n}=-S,\left( \frac{ \partial A }{ \partial V }  \right)_{T,n}=-P  &\implies \left( \frac{ \partial P }{ \partial T }  \right)_{V,n}=\left( \frac{ \partial S }{ \partial V }  \right)_{T,n}\\
G\implies & \left( \frac{ \partial G }{ \partial T }  \right) _{P,n}=-S,\left( \frac{ \partial G }{ \partial P }  \right)_{T,n}=V &\implies \left( \frac{ \partial V }{ \partial T }  \right)_{P,n}=-\left( \frac{ \partial S }{ \partial P }  \right)_{T,n}\end{align}$$
#### 2.3 压强、力与熵
压强的概念是从热力学中环境-系统之间一种能量交换作用的强度性质引入的。下面我们来探讨：**纯粹从系统状态函数来看，压强有何代表意义。**
上面4个能量类函数中，有两个量给出了压强的偏微分表示。其中$\displaystyle{P=-\left( \frac{ \partial U }{ \partial V } \right)_{S,n}}$中要求等熵，这一条件的实现很困难。因此，从亥姆霍兹自由能入手，有**压强**定义
$$P=-\left( \frac{ \partial A }{ \partial V }  \right)_{T,n}=-\left( \frac{ \partial (U-TS) }{ \partial V }  \right)_{T,n}=-\left( \frac{ \partial U }{ \partial V }  \right)_{T,n}+T\left( \frac{ \partial S }{ \partial V }  \right)_{T,n}$$
上式表明：**在温度和摩尔数维持恒定（等温、摩尔数不变）条件下，压强不仅取决于内能随体积变化率，还与系统熵随体积的变化率有关。** 实际上，当熵不变，即有此式等价于上式。
- 特别地，**对理想气体**，在温度和摩尔数恒定条件下，内能变化项为0（下证），即有**压强表征系统熵随体积的变化率**。

**力**：考虑对环境某一个小面积$a$施加的力$F$，选择垂直于$a$、由系统指向环境的方向为$x$方向
$$\vec{F}=a\cdot \vec{P}=--\left( \frac{ \partial U }{ \partial \frac{V}{a} }  \right)_{T,n}+T\left( \frac{ \partial S }{ \partial \frac{V}{a} }  \right)_{T,n}\xlongequal[]{ \displaystyle{ x\equiv \frac{V}{a} }  }\left[\underset{ 经典力 }{ -\left( \frac{ \partial U }{ \partial x }  \right)_{T,n} }+\underset{ 熵力 }{ T\left( \frac{ \partial S }{ \partial x }  \right)_{T,n} }\right]\vec{x}_{0}$$
其中$\vec{x}_{0}$为$x$方向的单位矢量。
上式表明：**热力学封闭系统对环境的作用力不仅包括能量场梯度的负值（即$\displaystyle{\left[ -\left( \frac{ \partial U }{ \partial x } \right)_{T,n} \right]}$），还包括系统熵梯度与温度的乘积**。
- 同上，**对理想气体**，在温度和摩尔数恒定条件下，内能变化项为0，即**封闭系统中理想气体施加于器壁的力完全源于系统熵梯度与温度的乘积**。

### 第3节 摩尔数可变系统基本方程
#### 3.1 化学势与热力学基本方程
我们继续讨论$\text{d}U$：
$$U=f(S,V,n_{1},\dots,n_{c})\implies  \text{d}U=\underbrace{ \left( \frac{ \partial U }{ \partial S }  \right)_{V,n} }_{ \equiv T }\text{d}S+\underbrace{ \left( \frac{ \partial U }{ \partial V }  \right)_{S,n} }_{ \equiv -P }\text{d}V+\underbrace{ \sum _{i=1}^{c}\left( \frac{ \partial U }{ \partial n_{i} }  \right)_{S,V,n\neq n_{i}} }_{ 其中n\neq n_{i}表示除n_{i}外其余摩尔数不变 }\text{d}n_{i}$$
现在讨论第三项：定义化学势
$$\mu _{i}\equiv \left( \frac{ \partial U }{ \partial n_{i} } \right)_{S,V,n\neq n_{i}}$$
则有
$$\text{d}U=T\text{d}S-P\text{d}V+\sum _{i}\mu _{i}\text{d}n_{i}$$
同理我们可以得到
$$\text{d}H=T\text{d}S+V\text{d}P+\sum _{i}\mu _{i}\text{d}n_{i}\implies  \mu _{i}=\left( \frac{ \partial H }{ \partial n_{i} }  \right)_{S,P,n\neq n_{i}}$$
注意这里偏导数的边界条件不同。
同理，可得
$$\text{d}A=-S\text{d}T-P\text{d}V+\sum _{i}\mu _{i}\text{d}n_{i}\implies  \mu _{i}=\left( \frac{ \partial A }{ \partial n_{i} }  \right)_{T,V,n\neq n_{i}}$$
$$\text{d}G=-S\text{d}T+V\text{d}P+\sum _{i}\mu _{i}\text{d}n_{i}\implies  \mu _{i}=\left( \frac{ \partial G }{ \partial n_{i} }  \right)_{T,P,n\neq n_{i}}$$
这两个表达式的边界条件更易于理解与控制。
上述表达式均要求在可逆热力学过程下的系统。
#### 3.2 麦克斯韦方程
在麦克斯韦关系式中补充化学势：
$$\begin{aligned}
&U:
&&\left( \frac{ \partial T }{ \partial  V}  \right)_{S,n}=-\left( \frac{ \partial P }{ \partial S }  \right)_{V,n}
&&\left( \frac{ \partial \mu _{i} }{ \partial S }  \right)_{V,n}=\left( \frac{ \partial T }{ \partial n_{i} }  \right)_{S,V,n\neq n_{i}}
&&\left( \frac{ \partial \mu _{i} }{ \partial S }  \right)_{V,n}=-\left( \frac{ \partial P }{ \partial  n_{i}}  \right)_{S,V,n\neq n_{i}}\\
&H:
&&\left( \frac{ \partial T }{ \partial P }  \right)_{S,n}=\left( \frac{ \partial V }{ \partial S }  \right)_{P,n}&&\left( \frac{ \partial \mu _{i} }{ \partial S }  \right)_{P,n}=\left( \frac{ \partial T }{ \partial n_{i} }  \right)_{S,P,n\neq n_{i}}
&&\left( \frac{ \partial \mu _{i} }{ \partial P }  \right)_{S,n}=\left( \frac{ \partial V }{ \partial n_{i} }  \right)_{S,P,n\neq n_{i}}\\
&A:
&&\left( \frac{ \partial S }{ \partial V }  \right)_{T,n}=\left( \frac{ \partial P }{ \partial T }  \right)_{V,n}
&&\left( \frac{ \partial \mu _{i} }{ \partial T }  \right)_{V,n}=\left( \frac{ \partial S }{ \partial n_{i} }  \right)_{T,V,n\neq n_{i}}
&&\left( \frac{ \partial \mu _{i} }{ \partial V }  \right)_{T,n}=-\left( \frac{ \partial P }{ \partial n_{i} }  \right)_{T,V,n\neq n_{i}}\\
&G:
&&\left( \frac{ \partial S }{ \partial P }  \right)_{T,n}=-\left( \frac{ \partial V }{ \partial T }  \right)_{P,n}
&&\left( \frac{ \partial \mu _{i} }{ \partial P }  \right)_{T,n}=\left( \frac{ \partial V }{ \partial {n_{i}} }  \right)_{T,P,n\neq n_{i}}
&&\left( \frac{ \partial \mu _{i} }{ \partial T }  \right)_{P,n}=-\left( \frac{ \partial S }{ \partial n_{i} }  \right)_{T,P,n\neq n_{i}}
\end{aligned}$$
#### 3.3 纯态理想气体的化学势
为了便于表达，我们选取$G$（$\text{d}G$为两强度性质$T,P$的函数）进行分析
$$G=nG_{m}\implies \mu=\left( \frac{ \partial G }{ \partial n }  \right)_{T,P}=G_{m}$$
给定$T$，探究$\mu$随$P$的变化（注意，我们探讨的是纯态即单组分理想气体）
$$\left( \frac{ \partial \mu }{ \partial P }  \right)_{T}\xlongequal[]{ \text{Maxwell} }\left( \frac{ \partial V }{ \partial n }  \right)_{P,T}=\left( \frac{ \partial  }{ \partial n  }  \frac{nRT}{P}\right)_{P,T}=\frac{RT}{P}\implies \mu-\mu^{\circ }=RT\ln \frac{P}{P^{\circ}}\quad (T=Const.)$$
其中$\mu^{\circ}$定义为标准态化学势，对应$P^{\circ}=\pu{ 1bar}$（注意对$T$没有要求）。变形，即得理想气体化学势
$$\boxed{ \mu=\mu^{\circ }+RT\ln \frac{P}{P^{\circ }}}$$
对理想气体，有$\displaystyle{ P=\frac{nRT}{V} }=CRT$，故在给定温度$T$下，原式变形得到浓度相关关系式
$$\boxed{ \mu=\mu^{\circ }+RT\ln \frac{c}{c^{\circ }}}$$
因此，给定$T$，$c\uparrow,\,\mu \uparrow$

> [!hint] 吉布斯佯谬
> 吉布斯佯谬 Gibbs Paradox 揭示了经典热力学在描述**气体混合过程**时的内在矛盾：两个相同容器（体积均为 $V$），分别装有一定量理想气体，$T$和$P$相同。移除隔板后，气体混合成总体积 $2V$，对每种气体，等温膨胀（体积 $V \to 2V$）的熵变为 $$\Delta S = \int _{i}^{f} \frac{\text{d}U}{T} + \int _{i}^{f} \frac{P\text{d}V}{T} = nR\ln \frac{2V}{V}= nR \ln 2 $$若两容器中气体不同，则每种气体贡献 $nR \ln 2$，总熵变 $$\Delta S_A = 2nR \ln 2$$若两容器中气体相同，按相同公式计算，也应得 $$\Delta S_B = 2nR \ln  2$$但直观物理事实表明，同种气体混合后，微观状态未改变，熵应不变。

这一问题的根源在于**粒子的全同性**，需用统计力学解决：
熵的定义为 $S = k_B \ln \Omega$
- 对不同气体，分子可区分 $\Omega_\text{混合} = \Omega_{A} \cdot \Omega_{B}$
- 对同种气体，分子全同不可区分，状态数需修正以避免重复计数
事实上，在计算定域和离域自由度时，我们已经讨论过这个问题，即对$N$个全同粒子，状态数需除以排列数$N!$ ，称为吉布斯因子
$$\Omega_\text{全同} = \frac{\text{粒子可区分时的状态数}}{N!}$$
修正后，对同种气体混合有：
初始状态：隔板存在时，两容器独立，总状态数为
$$\Omega_i = \frac{\Omega(n, V)}{n!} \cdot \frac{\Omega(n, V)}{n!} \quad \text{（每个容器有 \(n\) 摩尔）}$$
混合后：全同粒子在 $2V$ 中，状态数为
$$\Omega_f = \frac{\Omega(2n, 2V)}{(2n)!}$$
因此熵变比为
$$ \ln\left( \frac{\Omega_f}{\Omega_i} \right) = \ln\left[ \frac{\Omega(2n, 2V)}{\Omega(n, V) \cdot \Omega(n, V)} \cdot \frac{n! \cdot n!}{(2n)!} \right]$$

又对**理想气体，有系统的微观状态数与体积的粒子总数次幂成正比**
$$\Omega \propto V^N$$
代入即得
$$\Delta S_B = k_B \ln \left(2^{2n}\right) + k_B \ln \left( \frac{(n!)^2}{(2n)!} \right) \approx 2n k_B \ln 2 - 2n k_B \ln 2 = 0 \quad \text{Stirling 近似}$$
即：对于题述情景，**混合熵为0**。

进一步考虑，若两种气体性质逐渐**接近**（如不同同位素），混合熵从$2nR\ln2$到$0$的过程中是否连续变化？  
微观粒子具有**波粒二象性**，当两种气体分子的波函数重叠足够大时，**全同性显现**，**混合熵连续减小**，直到完全不可区分时降为0。

吉布斯修正通过考虑**粒子的全同性**解决了吉布斯佯谬，是熵的**广延性**的核心  
若忽略全同性，熵不满足广延性，如
$$S(2n, 2V) \neq 2S(n, V)$$
吉布斯修正后，熵成为广延量
$$S \propto N,\quad \text{而非}S\propto  N \ln N$$
因此，化学势 $\displaystyle{ \mu = \left( \frac{\partial G}{\partial N} \right)_{T,P} }$ 的正确表达依赖于吉布斯修正。

#### 3.4 摩尔数变化的第二定律($\text{d}w_{非}=0$)
$$\left.\begin{aligned} & T,P=Const.,\quad 0\geq \text{d}G=-S\underset{ =0 }{ \text{d}T }+V\underset{ =0 }{ \text{d}P }+\sum _{i}\mu _{i}\text{d}n_{i}
\\&T,V=Const.,\quad 0\geq \text{d}A=-S\text{d}T-P\text{d}V+\sum _{i}\mu _{i}\text{d}n_{i}
\\&S,V=Const.,\quad 0\geq \text{d}U=T\text{d}S-P\text{d}V+\sum _{i}\mu _{i}\text{d}n_{i}
\\&S,P=Const.,\quad 0\geq \text{d}H=T\text{d}S+V\text{d}P+\sum _{i}\mu _{i}\text{d}n_{i}\end{aligned}\right\}\implies \sum _{i}\mu _{i}\text{d}n_{i}\leq 0 $$
因此，这几个物理量均可作为热力学第二定律的判据
#### 3.5 摩尔数变化的第二定律($\text{d}w_{非}\neq0$)
$T,P=Const.$：
$$\text{d}S_{tot}=\text{d}S+\text{d}S_{surr}=\text{d}S-\frac{\text{d}U+P\text{d}V-\text{d}W_{非}}{T}=\frac{1}{T}(T\text{d}S-P\text{d}V-\text{d}U+\text{d}W_{非})$$
又有
$$\text{d}G=\text{d}(U+PV-TS)\xlongequal[]{ T,P=Const. }\text{d}U+P\text{d}V-T\text{d}S$$
则有
$$\text{d}S_{tot}=\frac{1}{T}(-\text{d}G+\text{d}W_{非})\implies 0\geq -T\text{d}S_{tot}=\text{d}G-\text{d}W_{非}$$
这就是存在非体积功的摩尔数变化的第二定律判据
$$\boxed{ \text{d}G=\sum _{i}^{}\mu _{i}\text{d}n_{i}\leq \text{d}W_{非}}$$
### 第4节 量子统计热力学与可逆过程热力学
#### 4.1  处理角度比较
可逆过程热力学注重过程，对状态描述不能很好适用；
量子统计热力学则从状态描述出发；
对过程的处理，两者一致。
#### 4.2 配分函数与热力学状态函数
我们期望仅用 $U,S,V,T$ 来刻画 $H,A,G,P,C_{V},C_{P}$
我们已有内能的配分函数表达
$$\boxed{ U=U(0)+nRT^{2} \left( \frac{ \partial \ln f_{tot} }{ \partial T }  \right)_{V,n}}$$
可用配分函数表示$S$
$$\boxed{S=nR\ln f_{tot}+ nRT \left( \frac{ \partial \ln f_{tot} }{ \partial  T}  \right)_{V,n}}$$
则对亥姆霍兹自由能有
$$A=U-TS=U(0)+Q-TS=U(0)+Q -T\left( \frac{Q}{T}+nR\ln f_{tot} \right)=U(0)-nRT\ln f_{tot}$$
即有
$$\boxed{ A=U(0)-nRT\ln f_{tot},\quad \Delta A=-nRT\ln \frac{f_{tot,f}}{f_{tot,i}}}$$
应当注意，这里的$U(0)$项表明，**基态能对亥姆霍兹自由能$A$同样有贡献**。
从此式出发，可得到压强用分子总配分函数表示：
$$P=-\left( \frac{ \partial A }{ \partial V }  \right)_{T,n}=-\left( \frac{ \partial U(0) }{ \partial V }  \right)_{T,n}+nRT\left( \frac{ \partial \ln f_{tot} }{ \partial V }  \right)_{T,n}$$
即有
$$\boxed{P=-\left( \frac{ \partial U(0) }{ \partial V }  \right)_{T,n}+nRT\left( \frac{ \partial \ln f_{tot} }{ \partial V }  \right)_{T,n}}$$
由此出发，即可进一步得到$H,G$的表达式。
则代入焓的定义式有
$$H=U+PV =U(0)+nRT^{2} \left( \frac{ \partial \ln f_{tot} }{ \partial T }  \right)_{V,n}+V\left[ -\left( \frac{ \partial U(0) }{ \partial V }  \right)_{T,n}+nRT\left( \frac{ \partial \ln f_{tot} }{ \partial V }  \right)_{T,n} \right]$$
即有
$$\boxed{ H=U(0)-V\left( \frac{ \partial U(0) }{ \partial V }  \right)_{T,n} + nRT\left[ T \left( \frac{ \partial \ln f_{tot} }{ \partial T }  \right)_{V,n} + V\left( \frac{ \partial \ln f_{tot} }{ \partial V }  \right)_{T,n} \right]}$$
同理，由吉布斯自由能的定义式
$$G=U+PV-TS=A+PV$$
代入即得
$$\boxed{ G=U(0)-nRT\ln f_{tot}-V\left( \frac{ \partial U(0) }{ \partial V }  \right)_{T,n}+nRTV\left( \frac{ \partial \ln f_{tot} }{ \partial V }  \right)_{T,n}}$$
比较发现，$A$的表达式最简单。这是因为，$A$对应的独立基本变量组为$(T,V)$，即定义式提到的**恒温恒容**条件下的反应趋势。而根据配分函数的计算公式，$(T,V)$恰也为配分函数的独立基本变量组。具体来说，$T$包含于所有能级类型的配分函数中，而$V$包含于平动配分函数中。
对理想气体，基态能与体积无关（前已证明），则进一步简化。
在等温等压条件下，对纯态物质有
$$\mu=\left( \frac{ \partial G }{ \partial n }  \right)_{P,T}=\frac{G}{n}$$
则也可类似用配分函数表示化学势$\mu$。
