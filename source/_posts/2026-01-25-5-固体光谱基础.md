### 5.1 半导体的基本能带结构
#### 直接能隙与间接能隙
半导体的**价带 valence band** 和**导带 conduction band** 之间有**带隙 band  $E_{g}$，对应费米能为eV级。室温下的热激发一般为26 meV，因此室温下难发生电子跃迁；如果加一束能量大于$E_{g}$的光，也能发生跃迁。
**直接能隙 Direct band gaps**：半导体材料的导带底的极小值和价带顶的极大值在k空间内对应**同一个**k值的能带结构，具有这种结构的半导体称为称直接带隙半导体。
**间接能隙 Indirect band gaps**：半导体材料的导带底的极小值和价带顶的极大值在k空间内对应**不同**k值的能带结构，具有这种结构的半导体称为间接带隙半导体。
![](Image1.png)
非直接跃迁是一个二级过程，其发生的机率很小（约为直接跃迁的1/1000）。相较之下，直接跃迁型材料更适合用作新型发光材料。
#### 晶体电子的有效质量
由德布罗意方程组有方程组
$$\left\{\begin{aligned}&p=\frac{h}{\lambda}=\hbar k \\&E=h\nu=\hbar\omega\end{aligned}\right. \implies \left\{\begin{aligned}&F=\frac{ \text{d}  p }{ \text{d} t }=\frac{ \hbar\text{d}  k }{ \text{d} t } \\& v=\frac{1}{\hbar}\nabla _{k}E(k)\end{aligned}\right.$$
此即**晶体中电子准经典运动的两个基本关系式**。
从这两个基本关系式出发，可以直接写出外力作用下加速度的公式。外力作用引起$k$随时间变化，从而引起速度随时间变化，即加速度写成分量形式。
$$\frac{ \text{d}  v_{\alpha} }{ \text{d}  t } =\frac{\text{d}}{\text{d}t} \left( \frac{1}{\hbar} \frac{ \partial  E(k) }{ \partial  k_{\alpha} }  \right)=\frac{1}{\hbar}\sum _{\beta} \frac{\text{d}k_{\beta}}{\partial t} \frac{ \partial   }{ \partial  k_{\beta} }  \left( \frac{ \partial  E(k) }{ \partial  k_{\alpha} }  \right)=\frac{1}{\hbar^{2}}\sum _{\beta}F_{\beta} \frac{ \partial  ^{2} }{ \partial  k_{\beta}\partial k_{\alpha} } E(k)$$
由此，可以列出
$$\begin{pmatrix}v_{x} \\ v_{y}\\ v_{z}\end{pmatrix}= \frac{1}{\hbar^{2}}
\begin{pmatrix}\displaystyle{\frac{ \partial^{2}E }{ \partial k_{x}^{2} }}  & \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{x} \partial k_{y} } }  & \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{x}\partial k_{z} } } \\\displaystyle{ \frac{ \partial^{2}E }{ \partial k_{y}k_{x} } }  & \displaystyle{ \frac{ \partial^{2} E}{ \partial k_{y}^{2} } }  & \displaystyle{ \frac{ \partial^{2} E}{ \partial k_{y}\partial k_{z} }  }\\ \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{z}\partial k_{x} }  } & \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{z}\partial k_{y} } }  & \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{z}^{2} }  }\end{pmatrix}\begin{pmatrix}F_{x}\\F_{y}\\F_{z}\end{pmatrix}$$
上式具有类似牛顿定律
$$\frac{\text{d}}{\text{d}t} v=\frac{1}{m}F$$
的形式，其中$\displaystyle{ \frac{1}{m} }$被一个二阶张量代替，称为**倒有效质量张量**。
若选$k_{x}, k_{y},k_{z}$轴沿张量主轴方向，则有其分量
$$\frac{1}{\hbar^{2}} \frac{ \partial^{2}E }{ \partial k_{\alpha}k_{\beta} }=\delta _{\alpha\beta}\left\{\begin{aligned}&\neq 0,& \alpha =\beta\\ &=0, &\alpha \neq \beta\end{aligned}\right.$$
此时，倒有效质量张量为**对角化**
$$\frac{1}{\hbar^{2}}\begin{pmatrix} \displaystyle{ \frac{ \partial^{2}E }{ \partial k_{x}^{2} } }  & 0 & 0\\ 0 & \displaystyle{ \frac{ \partial^{2}E }{ \partial  k_{y}^{2}} }   & 0 \\0 & 0 & \displaystyle{ \frac{ \partial^{2}E}{ \partial k_{z}^{2} } } \end{pmatrix}$$

在这种情况下，引入**有效质量张量**。
有效质量近似是为了便于引入经典力学牛顿第二定律作的一种近似，电子有效质量代表的是在晶体能带中电子受到晶格势场作用力时，**外力与能带中电子加速度**的一个比例系数，把晶体中电子准经典运动的加速度与外力直接联系了起来。有效质量与**能带形状、位置**有关。
$$\begin{pmatrix} m_{xx}^{*}  & 0 & 0\\ 0 & m_{yy}^{*} & 0\\0 & 0 & m_{zz} ^{*}\end{pmatrix}=\begin{pmatrix} \displaystyle{ \frac{\hbar^{2}}{\displaystyle{ \frac{ \partial^{2}E }{ \partial k_{x}^{2} } } } } & 0 & 0 \\0    & \displaystyle{ \frac{\hbar^{2}}{\displaystyle{ \frac{ \partial^{2}E }{ \partial k_{y}^{2} } } } }  & 0 \\ 0 &  0 & \displaystyle{ \frac{\hbar^{2}}{\displaystyle{ \frac{ \partial^{2}E }{ \partial k_{z}^{2} } } } }\end{pmatrix}$$
##### 带边的有效质量
**导带底附近的电子有效质量**和**价带顶附近的空穴有效质量**也是半导体能带的基本参数。
在极值$k_0$点附近，$E(k)$作**泰勒级数展开**，一次项为0，保留到二次项。
$$E(k)=E(k_{0})+ \frac{\hbar^{2}}{2m_{x}^{*}}(k_{x}-k_{0x})^{2}+\frac{\hbar^{2}}{2m_{y}^{*}}(k_{y}-k_{0y})^{2}+\frac{\hbar^{2}}{2m_{z}^{*}}(k_{z}-k_{0z})^{2}$$
此式表明，有效质量由极值附近能量函数$E(k)$的二次项决定。因此，估计有效质量就归结为求$E(k)$在极值附近展开式的**二次项**，带边电子有效质量和空穴有效质量与能带结构有关。
#### 半导体的杂质和电子导电性
实际半导体中除去与能带对应的共有化状态以外，还存在一定数目的**束缚状态**，由**杂质或缺陷(空位、间隙原子、位错)引起**，也就是说电子可以为适当的杂质或缺陷所束缚。正如一般电子为原子所束缚的情况，束缚电子也具有确定的能级，这种**杂质能级处在带隙**之间，对于实际半导体的性质起着决定性的作用。
**施主**：杂质在带隙中提供带有电子的能级。电子由**施主能级激发到导带**远比由满带激发容易(特别是在能级离导带底很近的情况)。因此，主要含施主杂质的半导体，导电往往几乎完全是依靠由施主热激发到导带的电子。这种主要依靠电子导电的半导体称为**N型半导体**。
**受主**：杂质提供带隙中空的能级。电子由**满带激发到受主能级**比激发到导带容易得。因此，主要含受主杂质的半导体，由于满带中有些电子激发到受主能级而产生许多空穴，则半导体的导电性主要依靠空穴。这种主要依赖空穴导电的半导体称为**P型半导体**。

### 5.2 半导体的本征光吸收
#### 固体光学常数间的基本关系
光在耗散介质中传播，需要考虑吸收的影响，引入介电常数的复数描述
$$\varepsilon(\omega)=\varepsilon_{1}(\omega)+i\cdot\varepsilon_{2}(\omega)$$
此时有电场为
$$\mathbfit{E}_{y}=\mathbfit{E}_{0}e^{ i(qx-\omega t) }$$
表明电磁波沿$x$方向传播，$E$与传播方向垂直。
在介质中，有
$$\mathbfit{D}=\varepsilon_{0}\mathbfit{E}+\mathbfit{P}=\varepsilon(\omega)\varepsilon_{0}E\implies \mathbfit{P}=\varepsilon_{0}[\varepsilon(\omega)-1]\mathbfit{E}$$
其中$\mathbfit{D}$为电位移矢量，$\mathbfit{P}$为极化强度。又有$\mathbfit{P}$随时间变化即电流密度，即有
$$\mathbfit{j}=\mathbfit{\dot{P}}=\varepsilon_{0}[\varepsilon(\omega)-1]\mathbfit{\dot{E}}=\varepsilon_{0}[\varepsilon_{1}(\omega)-1+i\cdot\varepsilon_{2}(\omega)](-i\omega)\mathbfit{E}=-i\omega\varepsilon_{0}[\varepsilon_{1}(\omega)-1]\mathbfit{E}+\omega\varepsilon_{2}(\omega)\varepsilon_{0}\mathbfit{E} $$
此式表明在吸收介质中，电流$j$分为两部分，一部分与$\mathbfit{E}$位相差90° - 极化电流，一部分与$\mathbfit{E}$同位相 - 传导电流。极化电流在一个周期内对电场做功为0，不消耗电磁场能量；传导电流有单位时间吸收能量（电磁场所耗散的能量）为
$$\omega\varepsilon _{2}(\omega)\varepsilon _{0}\overline{E^{2}}$$
因此，$\varepsilon _{2}(\omega)$与吸收功率之间存在内在联系。

进一步，电磁波在介质中传播，光速为$\displaystyle{\frac{c}{n}}$，其中$n=\sqrt{ \varepsilon }$为折射率，即$\displaystyle{\omega=\frac{c}{n}q}$
$$E_{y}=E_{0}e^{ i(qx-\omega t) }=E_{0}e^{ i\omega(\frac{nx}{c}-t) }$$
在吸收介质中，折射率也用复折射率形式表示
$$复折射率\qquad n=n+i\kappa $$
其中$\kappa$为消光系数，代入则有光入射后光强随金属固体材料的深度$x$衰减关系
$$E_{y}=E_{0}e^{ -\omega kx/c }e^{ i\omega ( \frac{nx}{c}-t) }$$
光强正比于$E^{2}$，所以**光强按$e^{ -2\omega kx/c }$衰减**，定义指数指标$\displaystyle{\frac{2\omega k}{c}}$为**吸收系数$\alpha$**，利用复折射率与复介电常数间的关系可得
$$(n+i\kappa)^{2}=\varepsilon=\varepsilon _{r}+i\varepsilon _{i}\implies \left\{\begin{aligned}&\varepsilon _{r}=n^{2}-\kappa^{2}\\&\varepsilon _{i}=2n\kappa\end{aligned}\right.$$
此式表明，用$\varepsilon_{1},\varepsilon_{2}$或$n,k$描述固体的光学性质，二者是等价的。
将其代入**吸收系数** $\alpha$
$$\alpha(\omega)=\frac{2\omega k(\omega)}{c}=\frac{\varepsilon_{2}(\omega)\cdot\omega}{n(\omega)\cdot c}$$
当光照射在固体表面，部分光被反射，若入射光强为 $J_0$，反射光强为$J_反$，则有**反射系数**
$$R=\frac{J_{反}}{J_{0}}$$
**反射光谱**即反映**反射系数对频率**的依赖关系$R=R(\omega)$的图线。

#### 带间跃迁的吸收与发射光谱
光照可以激发价带电子到导带，形成**电子-空穴对**，这个过程称为**本征光吸收**。
本征光吸收光子能量应满足
$$h\omega=\frac{2\pi \hbar c}{\lambda}\geq  E_{g}$$
长波限$\lambda_{0}=\frac{2p\hbar c}{E_{g}}$称为**本征吸收边**。在本征吸收边附近的光跃迁有两种类型：
- 直接跃迁：直接能隙，跃迁前后$k$不变；
- 间接跃迁：间接能隙，需要声子参与。
当固体从外界以某种形式(光、电及高能粒子)吸收能量，固体中电子将从基态被激发到激发态，此时固体被**激发**。
- 激发态电子会自发或受激地从激发态跃迁到基态，可能将能量以**光**形式辐射出来，这一过程叫**辐射复合**，即**发光**。
- 体系也可能以无辐射形式(如**发热**)将吸收的能量散发出来，这一过程叫**无辐射复合**。
##### 1. 允许的直接跃迁
对直接半导体中允许的直接跃迁，作**绝热近似和单电子近似**，可列出能量守恒和动量守恒
$$E_{i}+\hbar\omega=E_{f},\quad K_{i}+k=K_{f}$$
忽略光子的波矢$k$，则直接带跃迁的波矢关系为
$$K_{i}=K_{f}=K$$
则吸收过程的**吸收光谱**可以表示为
$$\alpha(\omega)=A\sum _{i,f}W_{i,f}n_{i}(E_{i})n_{f}(E_{f})$$
其中
- $W_{i,f}$为从初态$i$跃迁到末态$j$的**跃迁概率**；
- $n_{i}(E_{i}),n_{f}(E_{f})$分别为初态**被占据**的态密度和末态**未被占据**的态密度。
一般，初态被占据的几率是1，末态未被占据的几率也是1，因此可用初态和末态能态密度代替，即
$$\alpha(\omega)\approx A\sum _{i,f}W_{i,f}N_{i}(E_{i})N_{f}(E_{f})$$
采用**有效质量近似**，以价带顶作为坐标原点，在带边附近价带和导带为**抛物线型的能带结构**, 用$K$代表$\mathbfit{K}$的大小，有
$$E_{i}(K_{i})=- \frac{\hbar^{2}K_{i}^{2}}{2m_{h}^{*}}=-\frac{\hbar^{2}K^{2}}{2m_{h}^{*}},\quad E_{f}(K_{f})=E_{g}+ \frac{\hbar^{2}K_{f}^{2}}{2m_{e}^{*}}=E_{g}+ \frac{\hbar^{2}K^{2}}{2m_{e}^{*}}$$
由上讨论能量守恒得的波矢关系，有
$$\hbar\omega=E_{f}(K_{f})-E_{i}(K_{i})=E_{g}+ \frac{\hbar^{2}K^{2}}{2m_{e}^{*}}+\frac{\hbar^{2}K^{2}}{2m_{h}^{*}}\xrightarrow[定义电子-空穴对的约化质量]{ \displaystyle{ \mu ^{*}\equiv \frac{1}{m_{e}^{*}}+\frac{1}{m_{h}^{*}} }}E_{g}+ \frac{\hbar^{2}K^{2}}{2\mu ^{*}}$$
由此将吸收过程简化为**一个质量为$\mu ^{*}$，态密度为$J_{VC}$的电子-空穴对产生**过程，价带和导带状态密度的卷积简化为电子-空穴对的状态密度，定义其为（**价带-导带）联合态密度**$J_{VC}(E)$。在三维$k$空间中，波矢$K$对应的球壳体积为$4πK^2\text{d}K$。考虑自旋简并（自旋向上和向下），总状态数为
$$\text{d}N=J_{VC}(E)\text{d}E= \frac{2}{(2\pi)^{3}}4\pi K^{2}\text{d}K$$
由此可见，对于**直接跃迁吸收**，**吸收系数主要由联合态密度决定**，而联合态密度与能带的微商成反比。
若能带结构$E(k)$已知，则可以计算联合态密度$J_{VC}$，从而得到吸收光谱的表达式。
由上能量关系，有
$$E=E_{g}+ \frac{\hbar^{2}K^{2}}{2\mu ^{*}}\implies  K=\sqrt{  \frac{2\mu ^{*}(E-E_{g})}{\hbar^{2}} }\implies \text{d}K=\sqrt{ \frac{2\mu ^{*}}{4\hbar^{2}(E-E_{g})} }\text{d}E$$
则有
$$K^{2}\text{d}K= \frac{2\mu ^{*}(E-E_{g})}{\hbar^{2}}\cdot \sqrt{ \frac{2\mu ^{*}}{4\hbar^{2}(E-E_{g})} }\text{d}E= \frac{(2\mu ^{*})^{3/2}\sqrt{ E-E_{g} }}{2\hbar^{3}}\text{d}E$$
由此求解得(价带-导带)联合态密度 $J_{VC}(E)$
$$J_{VC}(E)= \frac{(2\mu)^{3/2}}{2\pi^{2} \hbar^{3}}\sqrt{ E-E_{g} }$$
由此可得吸收系数 - **Tauc 关系**
$$\alpha(\omega)=AW_{i,f} \frac{(2\mu ^{*})^{3/2}}{2\pi^{2}\hbar^{3}} (E-E_{g})^{1/2}\implies \boxed{ \alpha (\omega)=A^{*}(E-E_{g})^{1/2}}$$
对于折射率为$n=4$，有效质量可以采用自由电子质量
$$\alpha(E)=2\times 10^{4}(\hbar\omega-E_{g})^{1/2}  \text{ cm}^{-1}$$
可见，价带中能量为$E_{i}$，动量为$K_{i}$的电子，吸收$\displaystyle{ \hbar\omega=E_{g}+\frac{\hbar K^{2}}{2\mu ^{*}} }$的光子后，跃迁到导带中能量为$\displaystyle{ E_{f}=E_{g}+\frac{\hbar K^{2}}{2m_{e}} }$，动量为$K_{f}$的位置，吸收系数与光子能量服从$\displaystyle{ \frac{1}{2} }$次方的关系。由吸收光谱作$[\alpha(E)]^{2}-E$图，得线性吸收边，即得带隙$E_{g}$。
##### 2. 禁戒的直接跃迁
由于光学跃迁受到选择定则的限制，用吸收边确定的光学带隙与实际能级可能有所差别。如$\Delta L=\pm1$时，允许跃迁；但不满足$\Delta L=\pm 1$时，直接跃迁被选择定则所禁止，称为禁戒的直接跃迁。
对于某些直接带半导体材料,由于**结构对称性不同**，在$K=0$的跃迁是禁戒的，而$K\neq 0$的跃迁是允许的，即
$$W_{if}(K=0)=0,\quad W_{if}(K\neq 0)\neq 0$$
又有跃迁概率与$K^{2}$成正比
$$W_{if}(K\neq 0)\propto  \left| M_{V,C}(K) \right| ^{2}\propto K^{2}\propto (\hbar\omega-E_{g})$$
则有吸收系数
$$\alpha(\hbar\omega)=A'(\hbar\omega-E_{g})^{3/2},\quad A=\frac{4}{3} \frac{e^{2} \displaystyle{\left(\frac{m_{h}^{*}m_{e}^{*}}{m_{h}^{*}-m_{e}^{*}}\right)^{5/2}}}{nch^{2}m_{h}^{*}m_{e}^{*}\hbar\omega}$$
##### 3. 声子伴随的间接跃迁
对间接带结构半导体如$\ce{ Si}$，跃迁伴随有**声子的发射和吸收**。
声子波矢
$$-\frac{\pi}{a}\leq  q=\frac{2n\pi}{Na}< \frac{\pi}{a}$$
动量守恒：
$$K_{i}+q=K_{f}$$
能量守恒：从能量角度，光子可以吸收也可以发射一个声子，实现间接跃迁。
在有效质量近似和抛物线能带结构近似下，光子发射一个声子的能量
$$E_{e}=\hbar\omega _{e}=E_{f}-E_{i}+E_{p}=E_{g}+E_{p}+ \frac{ \hbar K_{c}^{2}}{2m_{e}^{*}}+ \frac{\hbar K_{V}^{2}}{2m_{h}^{*}}$$
吸收一个声子的能量
$$E_{a}=\hbar\omega _{a}=E_{f}-E_{i}-E_{p}=E_{g}-E_{p}+ \frac{ \hbar K_{c}^{2}}{2m_{e}^{*}}+ \frac{\hbar K_{V}^{2}}{2m_{h}^{*}}$$

###### 讨论：间接跃迁吸收光谱的温度依赖
对于直接跃迁，我们只考虑光子与电子相互作用，吸收光谱与温度基本无关。现在涉及到声子参与的间接跃迁，吸收光谱与温度可能密切相关。
$\hbar\omega > E_{g} -E_{p}$：只能吸收声子；
$\hbar \omega>E_{g}+ E_{p}$：可以吸收也可以发射声子

### 5.3 带间跃迁的量子力学处理
理论基础：含时间的微扰理论
$$\begin{align}&绝热近似\\&单电子近似\\&有效质量近似(EMA)\end{align}\implies  \begin{aligned}吸收光谱及所有光学函数的量子力学的表达\\
动量选择定则\\
布里渊区临界点及其在光跃迁中的作用\\
电偶极与电四极跃迁选择定则\end{aligned}$$
#### 相互作用哈密顿量
前已述，电磁波辐射场（光场）的**磁矢势**$A$可以描述为
$$A=A_{0}e^{ i(q\cdot\mathbfit{r}-\omega t) }+复共轭$$
矢量势与电场强度和磁场强度的关系为
$$E=-\frac{ \partial  A }{ \partial  t } ,\quad B=\nabla \times A$$
在光场作用下，电子动量为
$$\vec{p}=e\vec{A}$$
电子哈密顿量为
$$\begin{align}H&=\frac{1}{2m}(p+eA)^{2}+U(r)\\&=\frac{p^{2}}{2m}+U(r)+\frac{e}{m}A\cdot p+\frac{e^{2}}{2m}A^{2}\\&=H_{0}+H_{1}^{(1)}+H_{2}^{(2)}\end{align}$$
光场与电子相互作用的哈密顿量为
$$H_{1}=H^{(1)}=\frac{e}{m}\sum _{i=1}^{N}A(r_{i},t)\cdot p_{i}$$
光与物质的相互作用，归结为处理一个**含时微扰**的问题。在入射光不太强的情况下，光的作用可以看做对电子体系的微扰，微扰的结果导致光的吸收与发射。
#### 跃迁几率
含时微扰项为
$$H_{I}(r,t)=H_{I}(r)e^{ \pm i\omega t }$$
其中$e^{ \pm i\omega t }$为时间指数因子，$-$代表光吸收，$+$代表光发射。
![](Image5.png)
由费米黄金定则，**跃迁几率**
$$W= \frac{2\pi}{\hbar}\left| \braket{ c,k' | H_{I}|v,k }  \right| ^{2}\delta(E_{c}-E_{v}\mp \hbar\omega)$$
其中$\delta$因子代表跃迁过程中的能量守恒。
跃迁矩阵元$M_{c,v}(k)$满足
$$s\cdot M_{c,v}=\frac{q}{m}A_{0}\int \psi _{c,K_{c}}^{*}(e^{ \pm ik\cdot r }s\cdot P)\psi _{v,K_{v}}\text{d}\tau$$
其中$-$代表光吸收，$+$代表光发射。
将所有价带电子相加计算得吸收功率
$$吸收功率=2\times \hbar \omega \int W \frac{\text{d}k}{(2\pi)^{3}}$$
在积分中，实际上只有满足能量守恒、准动量守恒的跃迁才有贡献，$\displaystyle{ \int W \frac{\text{d}k}{(2\pi)^{3}} }$表示单位体积、单位时间内吸收能量为$\hbar\omega$光子的总跃迁次数，常数因子2表示考虑自旋，再乘以$\hbar\omega$即为吸收功率。
将跃迁几率和$M_{c,v}$矩阵元代入吸收功率得
$$吸收功率=2\times \frac{2\pi}{\hbar}\left( \frac{q}{m} \right)^{2}A_{0}^{2} \hbar^{2}\omega \int \left| s\cdot M_{c,v}(k) \right|^{2}\delta [E_{c}(k)-E_{v}(k)-\hbar\omega] \frac{\text{d}k}{(2\pi)^{3}}$$
又从宏观角度，有
$$\hbar\omega \cdot Z=\sigma \overline{E^{2}}=\varepsilon_{0}\omega \varepsilon _{i}(\omega)\overline{E^{2}}=2\varepsilon_{0}\omega^{3}\varepsilon _{i}(\omega)\overline{A_{0}^{2}}$$
联立两式，即得**介电常数虚部的量子力学表示**
$$\varepsilon _{i}(\omega)=\frac{\pi}{\varepsilon_{0}}\left( \frac{q}{m\omega} \right)^{2}\sum _{v,c}\left\{\int _{BZ} \frac{2}{(2\pi)^{3}}\left| s\cdot M_{v,c} \right| ^{2}\delta[E_{c}(K)-E_{v}(K)-\hbar\omega]\right\}$$
其中对波矢$K$求和，对自旋$S$求和，对$v,c$求和。这是介电常数虚部的微观表达式，可以看出它与晶体的能带结构密切相关。
由此可得**吸收系数**
$$\alpha(\omega)=\frac{2\omega\kappa}{c}=\frac{\omega\varepsilon _{i}(\omega)}{nc}=\frac{\pi}{\varepsilon_{0}} \frac{e^{2}}{ncm^{2}\omega}\cdot \left\{ \int _{BZ} \frac{2\text{d}K}{(2\pi)^{3}}\left| a\cdot M_{v,c} \right| ^{2}\delta[E_{c}(K)-E_{v}(K)-\hbar\omega] \right\} $$
可以看出，上两式**将宏观光学常数与微观能带结构、跃迁矩阵元和状态密度联系起来**。已知固体能带结构，原则上可以对固体的各种宏观光学常数进行近似计算与实验值相比较。近似计算的自洽性和得到的各种参数的合理性可以用光学常数求和法则来检验。

> [!hint] 吸收系数表达式中包括折射率$n$和频率$\omega$应该做变数处理，但是它们引起的变化比跃迁矩阵元和态密度对吸收光谱的影响较小，因此一般作为常数。
#### 联合态密度和**Van Hove**奇点
$\varepsilon _{i}(\omega)$的谱线形状很大程度上取决于**联合态密度**
$$J_{cv}(\hbar\omega)=\int\delta[E_{cv}(k)-\hbar\omega] \frac{2\text{d}k}{(2\pi)^{3}}\xrightarrow[]{ \displaystyle{ \text{d}k=\frac{\text{d}E_{cv}}{|\nabla _{k}E_{cv}(k)|}\text{d}s } } \frac{2}{(2\pi)^{3}}\int _{E_{cv}=\hbar\omega} \frac{\text{d}s}{\left| \nabla _{k}E_{cv}(k) \right| }$$
其中$E_{cv}(k)\equiv E_{c}(k)-E_{v}(k)$。
此式具有态密度的意义，而$E(k)$同时联系价带和导带，故称。
在$\varepsilon _{i}(\omega)$表达式中，矩阵$s\cdot M_{cv}$随$k$缓慢变化，可近似视为常数，可提到积分号外，故有
$$\varepsilon _{i}(\omega)\propto \frac{1}{\omega^{2}}\left| M_{v,c} \right| ^{2}\cdot J_{cv}\propto J_{cv}$$
称满足下面条件的点为**布里渊区的临界点**，或**Van Hove奇点**
$$\nabla _{k}[E_{c}(k)-E_{v}(k)]=\nabla _{k}E_{cv}(k)=0$$
在Van Hove奇点，联合态密度$J_{cv}$和$\varepsilon _{i}(\omega)$表现出典型结构，即微商呈现出某种典型的不连续性。

### 5.4 激发态载流子的可能运动方式
价带电子吸收光后被激发到导带（同时在价带产生空穴）成为**激发态载流子**，其运动方式分为两类

**能量弛豫**：趋向低能态，但不涉及复合 - 不减少载流子浓度，只降低能量
- **带内跃迁**：电子在导带内（或空穴在价带内）通过发射/吸收声子或光子，从高能级跃迁到低能级
- **子带间跃迁**：仅在量子阱/超晶格等结构中存在，电子在导带的子能级间跃迁（需满足量子限制条件）
- **晶格弛豫**：通过电子-声子相互作用，载流子能量转化为晶格振动热能，使导带非平衡态的载流子达到热平衡
	- **热均化**：导带电子通过频繁**声子散射**达到准平衡
	- **自陷态形成**：强电子-声子耦合下电子**局域化**

**复合**：电子-空穴对的消失，能量通过声子/光子释放 - 减少电子-空穴对数量
- **无辐射复合**
	- **多声子发射**：通过**高阶声子耦合**回到基态，常见于宽禁带半导体
	- **俄歇复合**：**三体过程**，能量传递给第三个载流子，在高载流子浓度下显著
	- **缺陷辅助复合**：通过**杂质/缺陷态**发生
- **辐射复合**：导带电子与价带空穴直接结合发射光子

#### 带间复合发光
- 光致发光 (Photoluminescence, PL)
- 电致发光 (Electroluminescence, EL, 也叫做场致发光)
- 阴极射线发光(Chathodoluminescence, CL)
- X射线及高能粒子发光
- 生物发光 (Bioluminescence)
- 摩擦发光 (Triboluminescence)
- 化学发光 (Chemiluminescence)
- 热释光 (Thermoluminescence, TL)
##### 带间复合发光关系 PL
对带-带复合，可将发光简单理解为吸收逆过程
吸收过程测量**入射光子衰减的平均自由程**，发光过程测量**单位体积的光子产生率**
吸收过程包括价带所有占据态及导带所有可能空态间的耦合（**联合态密度**），所以固体**吸收谱**一般为**宽谱带**，有吸收边
发光来自导带中**激发态电子复合**，因此带间复合发光来自导带底狭窄范围内的电子与价带空穴的复合，形成**窄谱带**
类似吸收过程，对于发光定义**辐射率$L$**
$$L(\nu)=n_{u}n_{l}W_{em}$$
其中$n_{u}$为导带能级被电子占据的电子态密度，$n_{l}$为价带能级空穴态密度，$W_{em}$为单位体积的辐射跃迁几率。

> -不伴随光电导
> -低温试验
> 
> ![](Image10.png)

因此：这些分立峰不是来自价带到导带的跃迁引起的，可能由价带电子被激发到**导带底部以下某些分立能级**引起
#### 激子跃迁假设
**激子**是固体中的元激发态或激发态的量子，可简单理解成**束缚的电子-空穴对**。
从价带激发到导带的电子通常是自由的，其和在价带自由运动的空穴可能**重新形成束缚的电子-空穴对**，即激子。
由于束缚，激子能量低于自由电子能量。由此可解释激子吸收能量低于带隙$E_g$，以及激子吸收峰分布在带-带间跃迁吸收边的低能方向。
激子为电中性，在晶体中运动传输激发能量但不传输电荷，故对电导没有贡献。
根据激子束缚能大小，提出了两种激子模型：**紧束缚激子**和**弱束缚激子**
A **弗仑克尔激子 - 紧束缚激子**：半径小（一个原子范围），束缚能大
B **万尼尔激子 - 弱束缚激子**：半径大（数十到几百原子范围），束缚能小
![](Image11.png)
#### 弗伦克尔激子
在一些特殊绝缘晶体（如惰性气体晶体、碱卤晶体、分子晶体）中，激发高度局域化，可能局限在某个原子上，形成**紧束缚状态：弗仑克尔激子**，其**可以在晶体内传播**（与孤立原子的激发不同）。
电子和空穴库仑相互作用能
$$U(r)=- \frac{e^{2}}{4\pi\varepsilon _{0}\varepsilon r}$$
Frenkel 型激子问题要用紧束缚近似来处理，以原子波函数构建激子波函数。
若将晶体中一个原子的激发看成一个谐振子，那么这个谐振子在晶体中原子间的耦合类似于晶格振动的传播，其解是布洛赫函数。计算和推导过程此处从略，不作要求，以了解形成机制为主。
晶格常数为 $a$ 的一维晶体，计算得弗伦克尔激子的能谱为
$$E_{K}=E_{n}+2I\cos \vec{K}\cdot \vec{a}$$
其中激子波矢$\vec{K}$与晶格振动的波矢一样，只能取离散值
$$\vec{K}\cdot \vec{a}=2n\pi,\quad n=1,2,\dots \implies K=\frac{2n\pi}{Na}$$
其中$N$为一维晶体的原胞总数，故弗伦克尔激子的结合能可能达到几个eV。

#### 万尼尔激子
当电子-空穴对的束缚半径比原子半径大得多时，形成弱束缚激子。
从电子和空穴库仑相互作用能公式
$$U(r)= - \frac{e^{2}}{4\pi\varepsilon_{0}\varepsilon r}$$
可看出，因为激子束缚半径较大，固体介电常数$\varepsilon$可看做常数，则$U(r)$只是电子-空穴对距离$r$的函数，体系哈密顿量与氢原子相似。
利用有效质量近似，万尼尔激子体系的哈密顿可以表示为
$$H=\frac{P_{e}^{2}}{2m_{e}^{*}}+ \frac{P_{h}^{2}}{2m_{h}^{*}}- \frac{e^{2}}{4\pi\varepsilon_{0}\varepsilon \left| r_{e}-r_{h} \right| }$$
激子能量本征值的计算类似氢原子能量本征值计算，过程从略。
以价带顶为参照点，**弱束缚万尼尔激子的能谱**可表示为
$$E_{ex}=E_{g}-\frac{R^{*}}{n^{2}}+ \frac{\hbar^{2}K^{2}}{2(m_{e}^{*}+m_{h}^{*})}$$
